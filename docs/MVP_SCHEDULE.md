## 五、MVP 验收清单（7/30）

| # | 验收项 | 标准 |
|---|--------|------|
| 1 | 启动正常 | 后端 + 前端都启动，不报错 |
| 2 | 演示模式生效 | 不配 API Key 也能走完，不返回 `{}` |
| 3 | 真实模式可用 | 配 API Key → 返回 LLM 真实生成的内容 |
| 4 | 前端正常 | 浏览器无白屏，表单完整 |
| 5 | 诊断有内容 | 学习风格、推荐难度、≥3 个知识盲区 |
| 6 | 资源有内容 | ≥1 份资源，Markdown 渲染正常 |
| 7 | 不同输入不同结果 | 换学历/目标 → 诊断和资源都跟着变 |
| 8 | 三种资源类型可选 | lecture / guide / quiz 分别不同内容 |
| 9 | 错误提示友好 | 后端没启动时前端不白屏 |
| 10 | Agent 2 不依赖 KB | 不传 retrieved_chunks 时正常生成 |
