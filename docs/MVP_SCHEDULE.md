### 7/25（周五）— MVP 验收测试

| 时间 | 事项 | 谁 | 验收标准 |
|------|------|-----|---------|
| 上午 | 正式验收 | 全员 | 按验收清单逐条测 |
| 下午 | 不达标项修复 | 角色1+相关人 | 修到全部通过 |

**验收清单：**

- [ ] `start.bat` 双击能启动，不报错
- [ ] 浏览器打开 http://localhost:8501 能看到页面
- [ ] **不配 API Key** 也能走完流程（演示模式生效）
- [ ] 填好学习者信息 → 点生成 → 看到诊断结果
- [ ] 诊断结果包含：学习风格、推荐难度、至少 3 个知识盲区、知识掌握度
- [ ] 看到至少 1 份学习资源（讲义或实操指南）
- [ ] 选择不同的资源类型（lecture/guide/quiz）能返回不同内容
- [ ] 换一组差异大的学习者信息，诊断结果真的不同（不总是输出同一份模拟数据）
- [ ] `/health` 显示 `kb_docs` > 0
- [ ] 后端没有崩溃，前端没有白屏
