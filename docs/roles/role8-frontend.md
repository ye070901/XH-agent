# CLAUDE.md — 角色8：前端 + 可视化

## 你的模块

`frontend/` — React + TypeScript + Vite

## 你要做的事情

1. 搭建 React 前端框架（Vite + TypeScript）
2. 实现三个核心可视化（评分标准15分的关键）：
   - **Agent 协同拓扑图**：实时显示 3 个 Agent 的消息流向
   - **知识溯源图**：每条生成内容的来源标注，点击回溯 KB 原文
   - **学习路径规划图**：知识状态变化可视化
3. 学习者画像输入页
4. 资源展示页
5. 学情报告页（含雷达图）
6. WebSocket 连接（接收 Agent 状态推送）

## 你的接口

- 后端 API: `http://localhost:8000/api/*`
- WebSocket: `ws://localhost:8000/ws/{task_id}`
- 数据模型: 参考 `backend/src/schemas.py` 的请求/响应定义

## 三个可视化的具体设计

### 1. Agent 协同拓扑图
- 3 个节点（诊断/生成/审核）用箭头连接
- 当前活跃的 Agent 高亮（WebSocket 状态推送）
- 辩论时 Agent 2↔Agent 3 来回闪烁
- 辩论轮次计数器

### 2. 知识溯源图
- 生成的资源内容，悬停在 `[ref:N]` 上弹出 KB 原文
- 侧边栏显示所有 citation 列表

### 3. 学习路径图
- 展示学习者的知识状态：已掌握(绿) / 学习中(黄) / 待攻克(红)
- 节点间显示前置依赖关系

## 关键约束

- 如果时间不够，先用 Streamlit 快速原型，保证功能闭环
- 演示视频的叙事 > UI 精致度
- 你的输出直接影响评分标准的"用户体验15分"
