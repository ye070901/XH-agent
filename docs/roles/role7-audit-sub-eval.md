# CLAUDE.md — 角色7：测试执行 + Phase 2 评估方案

## 你的任务（MVP 阶段）

MVP 不放 Agent 3。你的工作是执行测试 + 为 Phase 2 指标评估铺路。

## MVP 要做什么

1. **设计测试用例（7/19-21）**
   - 文件：新建 `docs/MVP_TEST_CASES.md`
   - 5 组差异化学习者输入，每组包含：
     - 学习者信息 + 学习目标 + 资源类型
     - 期望的诊断结果预判（学习风格、难度、至少该有哪些盲区）
     - 期望的资源质量预判（该覆盖哪些知识点、不该有什么错误）

2. **执行测试 + 记录结果（7/22-24）**
   - 用角色6 的测试脚本跑一遍
   - 人工检查每组输出：诊断合理吗？资源质量可接受吗？有事实错误吗？
   - 把结果填到测试用例文档里

3. **设计 Phase 2 三项指标评估方案（7/24-25）**
   - 文件：新建 `docs/PHASE2_EVALUATION_PLAN.md`
   - 回答三个问题：
     1. 幻觉率怎么算？（谁来判定？样本量多大？）
     2. 适配率怎么算？（怎么判断"真的适合"？）
     3. 覆盖率怎么算？（skill_gaps 怎么和 resources 对应？）
   - 每个指标给出计算公式和验证方法

**详细步骤见：** `docs/MVP_TASKS.md` — 角色7 部分
