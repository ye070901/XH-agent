# 头脑风暴方法速查表

快速选择指南。详细说明见 `methods-detailed.md`。

## 发散类方法（产生新想法）

| 方法 | 最适合 | 一句话 |
|------|--------|--------|
| **SCAMPER** | 改进现有概念 | 系统化提示：替代、组合、适应、修改、他用、消除、重排 |
| **随机刺激** | 打破思维僵局 | 引入不相关的词/图片，强制连接 |
| **强制类比** | 获取新视角 | "[某行业/某人物] 会怎么解决这个问题？" |
| **思维导图** | 探索想法空间 | 从中心概念向外发散的视觉化分枝 |
| **最差可能方案** | 解除限制 | 先想最差的主意，再反转 |
| **TRIZ 原理** | 技术/产品问题 | 解决矛盾的 40 个发明原理 |

## 收敛类方法（聚焦和决策）

| 方法 | 最适合 | 一句话 |
|------|--------|--------|
| **亲和图** | 组织大量想法 | 把相似想法聚类，给聚类命名 |
| **点投票** | 快速优先级排序 | 把有限票数分配给各选项 |
| **加权评分** | 复杂决策 | 按加权标准打分 |
| **淘汰轮次** | 缩小选项 | 按明确标准逐轮淘汰 |
| **2×2 矩阵** | 比较权衡 | 在两个关键维度上画选项位置 |

## 问题界定类方法

| 方法 | 最适合 | 一句话 |
|------|--------|--------|
| **第一性原理** | 彻底重新思考 | 拆解到最基础的事实，从头重建 |
| **5 个为什么** | 根本原因分析 | 反复问"为什么"直到找到核心问题 |
| **逆向思维** | 找到隐性风险 | "怎么保证这件事一定失败？"然后避开 |
| **问题重述** | 被困在错误的问题上 | 用 5 种不同方式重新表述问题 |
| **任务-要完成** | 产品/服务设计 | 用户"雇用"这个产品来完成什么任务？ |

## 视角转换类方法

| 方法 | 最适合 | 一句话 |
|------|--------|--------|
| **六顶思考帽** | 结构化群体分析 | 轮流切换：事实、感受、风险、收益、创意、流程 |
| **钢人辩论** | 严格测试想法 | 为反对观点建立最强论证 |
| **受众现实检查** | 产品/内容验证 | [具体的某个人] 真的会想要这个吗？ |
| **利益相关者地图** | 复杂决策 | 谁在乎、他们想要什么、他们的权力有多大？ |
| **时间视野** | 战略思考 | 1周/1年/10年后这个决定看起来如何？ |

## 评估与风险类方法

| 方法 | 最适合 | 一句话 |
|------|--------|--------|
| **事前验尸** | 承诺之前 | 假设它失败了——为什么？ |
| **假设浮现** | 基础清晰度 | 我们理所当然地接受了什么？ |
| **10/10/10** | 决策清晰度 | 10分钟/10个月/10年后我对此的感受？ |
| **可逆性测试** | 风险评估 | 这是单行道还是双行道？ |

## 快速选择启发式

- **"我没有想法"** → 随机刺激、最差可能方案
- **"我太多想法了"** → 亲和图、淘汰轮次
- **"我不确定真正的问题是什么"** → 5 个为什么、问题重述
- **"这感觉很冒险"** → 事前验尸、逆向思维
- **"我是不是漏了什么？"** → 六顶思考帽、钢人辩论
- **"这真的有价值吗？"** → 任务-要完成、受众现实检查
- **"我们假设了什么？"** → 第一性原理、假设浮现

## 方法组合推荐

### 产品构思
1. 任务-要完成（理解需求）
2. SCAMPER 或 强制类比（产生选项）
3. 加权评分（评估选项）
4. 事前验尸（测试胜出方案）

### 战略决策
1. 第一性原理（清空地基）
2. 六顶思考帽（全面分析）
3. 钢人辩论（测试结论）
4. 假设浮现（识别风险）

### 创意突破
1. 随机刺激 或 最差可能方案（打破僵局）
2. 亲和图（寻找模式）

### "我该不该做？"决策
1. 目的审视（这为什么重要？）
2. 事前验尸（哪里会出错？）
3. 逆向思维（怎么保证失败？）
