# 会话类型参考

## 会话类型识别

| 会话类型 | 典型触发词 |
|---------|-----------|
| **产品/SaaS 构思** | "应用想法""SaaS""产品""构建""创业""MVP" |
| **内容构思** | "newsletter""文章""博客""书""章节""内容" |
| **战略决策** | "我该不该""在……之间选择""权衡""战略" |
| **问题解决** | "卡住了""想不出""怎么做到""挑战""困难" |
| **创意/艺术** | "故事""设计""创意""艺术方向" |
| **商业模式** | "定价""收入""商业模式""变现" |
| **定位/营销** | "差异化""定位""信息传达""受众" |

## 各类型推荐方法

### 产品构思
1. **任务-要完成** — 理解真实需求
2. **受众现实检查** — 验证目标用户确实存在
3. **第一性原理** — 质疑继承下来的假设
4. **事前验尸** — 在承诺之前找到失败模式
**警惕：** 验证问题之前就爱上了解决方案

### 内容构思
1. **思维导图** — 探索想法空间
2. **受众现实检查** — 谁具体会想要这个？
3. **强制类比** — 找到新角度
4. **SCAMPER** — 在现有想法上变异
**警惕：** 写容易写的而不是需要的；追逐潮流而非构建作品体系

### 战略决策
1. **第一性原理** — 清除假设
2. **加权评分** — 让权衡显性化
3. **事前验尸** — 测试领先选项
4. **钢人辩论** — 为你准备放弃的选项辩护
5. **10/10/10** — 用时间视野检验
**警惕：** 在真正探索之前就做了决定；确认偏差

### 问题解决
1. **5 个为什么** — 找到根本原因
2. **问题重述** — 用多种方式重新表述问题
3. **逆向思维** — 什么会保证失败？
4. **强制类比** — 其他领域怎么解决这个问题？
5. **第一性原理** — 拆到最基础
**警惕：** 解决了错误的问题；太快跳到解决方案

### 商业模式
1. **任务-要完成** — 用户真正买的是什么？
2. **强制类比** — 类似商业模式怎么定价？
3. **第一性原理** — 价格到底是什么？
4. **假设浮现** — 这个模式要成功，什么必须是真的？
**警惕：** 定价过低；复制不合适的模式；在桌上留钱

## 会话能量模式

### 深度探索模式
- 不急于收敛
- 允许发散和跑题（不相关的放进 parking lot）
- 结束时做综合，不是做决定

### 快速推进模式
- 开始前明确："今天需要做什么决定？"
- 主要用收敛类方法
- 发散探索限时 10 分钟
- 结束时明确下一步行动

## 模式选择：关联 vs 全新

### 关联模式
- 交叉引用其他项目和现有工作
- "这和你之前对 X 的思考有关"
- "你在 [项目] 里探索过类似的"
- 适合：在现有工作基础上建设

### 全新模式
- 不引用其他项目或过往工作
- 全新视角
- 适合：真正的新领域，避免旧思路锚定
