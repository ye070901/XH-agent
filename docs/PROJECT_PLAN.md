### 边界测试（角色7 构造）

| # | 测试场景 | 验证什么 |
|---|---------|---------|
| 1 | 极端低水平：几乎零基础 | 系统能否降维解释而不出错、不自相矛盾 |
| 2 | 极端高水平：已从业 5 年 | 系统能否生成进阶内容而非重复基础 |

| 4 | KB 覆盖边界：问某 API 在最新版本中的变化 | 不编造不存在的版本信息 |
| 5 | 模糊输入：学习者没说清楚自己会什么 | 系统能否追问而非瞎猜 |

## 五、三项硬指标

| 指标 | 目标 | 计算方式 | 所需样本量 |
|------|------|---------|-----------|
| **幻觉率** | < 5% | 错误断言数 / 总断言数 | 30 次生成 ≈ 150-300 条断言 |
| **难度适配率** | ≥ 85% | 难度匹配的资源数 / 总资源数 | 30 次生成 |
| **知识点覆盖率** | ≥ 90% | 被覆盖知识点数 / 目标知识点总数 | 30 次生成 |

指标计算由角色7 的 `backend/src/evaluation/metrics.py` 自动完成。

## 七、降级方案

| 场景 | 降级 | 影响 |
|------|------|------|
| **辩论协议做不出来**（8/13 确认） | 回退到交叉验证：Agent 3 独立评分，不通过则打回重生成 | 创新分从 25→20 左右 |
| **前端进度落后**（8/20 确认） | 降级到 Streamlit（纯 Python UI），2 天可替代 | 体验分从 15→10 左右 |
| **指标 8/29 仍不达标** | 文档诚实写"在 XX 条件下达标，YY 边界需人工审核" | 实用分从 30→22 左右 |
| **视频来不及**（9/1 确认） | 屏幕录制 + 画外音，舍弃真人出镜 | 隐性丢分 |
| **某人生病/掉队** | 角色1 顶上，该 Agent 降级为简化版 | 特定模块质量下降 |
