## 正文

### 1. 点云配准要解决什么问题

把两个在不同坐标系下获取的点云，通过刚体变换（旋转+平移）对齐到同一坐标系，称为配准。在机器人视觉中典型应用包括：

- 多视角扫描结果拼接成完整工件点云；
- 实测工件点云与 CAD/标准模型点云对位，用于定位引导与偏差检测；
- 视觉获取位姿与机器人位姿之间的转换（配合手眼标定）。

### 2. ICP 原理

ICP（Iterative Closest Point）通过迭代最小化两组点云间的误差：

1. 对源点云中的每个点，在目标点云中寻找最近点建立对应；
2. 计算使对应点对距离误差最小的刚体变换（旋转 R、平移 t）；
3. 应用变换后重新建立对应；
4. 重复直到收敛（变换变化或误差小于阈值、或达到最大迭代次数）。

每次迭代求解可通过奇异值分解（SVD）或最小二乘完成。PCL 提供 `pcl::IterativeClosestPoint<PointXYZ, PointXYZ>` 实现。

### 3. 工程要点与鲁棒性

| 要点 | 说明 |
|------|------|
| 初始化对齐 | 原生 ICP 需要较好的初始位姿，否则陷入局部最优；先用粗配准 |
| 降采样 | 配准前用 VoxelGrid 降采样，提高速度与稳定性 |
| 剔除异常对应 | 设置最大对应距离，剔除远距离误对应 |
| 特征选择 | 只对高显著性区域配准可提升精度 |
| 多分辨率策略 | 由粗到细逐步提高精度 |

### 4. 配准精度评估

- **收敛误差（fitness）**：最近点对应均方根误差；
- **对应点数**：有效对应点占比越高越可靠；
- 用已知真值的变换验证配准结果误差，确认满足工艺公差。

### 5. 验证与常见问题

| 现象 | 原因与对策 |
|------|------------|
| 配准收敛到错误位置 | 初值太差，先做粗配准 |
| 收敛但精度不足 | 降采样过粗/对应剔除不当，细化参数 |
| 迭代发散 | 对应关系噪声大，增大最大对应距离阈值前先降噪 |
| 对称工件无法区分 | 特征相似导致解不唯一，引入额外约束 |

验收：用已知位姿的仿真点云或实测金标准验证配准误差；在真实工件变化范围内保持稳定对位。
