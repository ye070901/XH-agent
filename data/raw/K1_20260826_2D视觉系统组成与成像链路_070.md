## 正文

### 1. 2D视觉系统的组成

2D 机器视觉系统由以下基本部分构成，任何一环不当都会直接影响机器人引导或检测的稳定性：

| 组成 | 作用 | 选型关注点 |
|------|------|------------|
| 工业相机 | 将目标的光信号转换为数字图像 | 分辨率、帧率、芯片尺寸、接口（GigE/USB3）、曝光方式 |
| 镜头 | 决定视场、景深与成像清晰度 | 焦距、光圈、畸变、像圈与传感器匹配 |
| 光源与照明装置 | 决定目标特征与背景的对比度 | 光型（环形/背光/同轴/条形）、波长、照射角度 |
| 采集卡/接口 | 将图像数据高速传给处理单元 | 传输带宽、触发与同步能力 |
| 图像处理软件 | 定位、测量、识别与结果输出 | 算法库、标定支持、与机器人通讯接口 |

2D 视觉只能获取目标的 x、y 平面位置与图像平面内的旋转角度，不能直接获得深度信息；例如一个平放工件的偏摆角度可以通过模板匹配得到，但其离地高度变化在 2D 下难以量化，这正是需要 3D 视觉的场景。

### 2. 成像链路与关键环节

完整的 2D 视觉成像链路为：

```
光源照明 → 镜头成像 → 相机光电转换 → 图像传输 → 图像预处理
    → 特征提取/定位/测量 → 坐标转换（标定） → 结果输出给机器人
```

工程上最容易被低估的一环是**照明**：同样的相机与镜头，光源角度、颜色和光型不同，图像对比度可相差数倍。其次是被忽略的**镜头畸变与相机内参标定**：未标定的图像坐标不能直接换算为机器人工作空间坐标。

### 3. 像素精度与视场估算

像素精度（每像素对应的实际物理尺寸）是 2D 系统最基础的设计指标：

```
像素精度(mm/像素) = 视场宽度(mm) / 传感器水平分辨率(像素)
```

例：视场宽 200 mm，相机分辨率 2448 像素，则像素精度约 0.082 mm/像素。若需求是定位精度 ±0.5 mm，则该配置通常满足要求；若需求达到 ±0.05 mm，视场与分辨率必须相应调整（缩小视场或提高分辨率）。

### 4. 2D 系统的适用与不适用场景

| 适用 | 不适用 |
|------|--------|
| 平面工件的定位与抓取（平放、姿态已知） | 堆叠工件、散乱堆放的深度判断 |
| 平面尺寸测量、表面缺陷检测 | 高度差、形变、凹凸检测 |
| 条码/二维码/字符读取 | 大纵深场景的无标定引导 |
| 在标定平整面的高精度引导 | 玻璃、镜面等高反光表面（需特殊光源） |

### 5. 常见问题与排查顺序

| 现象 | 可能原因 | 排查方向 |
|------|----------|----------|
| 图像过曝/过暗 | 光源亮度、曝光时间不匹配 | 先调曝光与光圈，再换光源 |
| 目标与背景对比度差 | 照明角度/波长不合适 | 调整光型与颜色 |
| 边缘模糊 | 对焦不准、快门过长、镜头分辨率不足 | 检查对焦与运动模糊 |
| 定位漂移 | 相机松动、温漂、光源老化 | 固定相机并定期复标定 |

排查遵循"先照明、再对焦、后标定"的顺序，不要一上来就改算法参数。
