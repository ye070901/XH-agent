## 正文

### 1. 双目立体视觉原理

两个相机从不同角度观察同一目标，目标在左右图像中的成像位置存在**视差（disparity）**。视差与目标到基线平面的距离成反比：目标越近，视差越大。通过三角测量可由视差计算深度，这是双目立体视觉获取 3D 信息的基础。

### 2. 双目系统标定流程

双目系统要精确计算深度，需要完整标定：

1. **单目标定**：分别标定左右相机的内参（焦距、主点）与畸变；
2. **双目标定**：联合标定左右相机间的相对外参（旋转 R、平移 T）；
3. **立体校正（Rectification）**：对左右图像做变换，使对应点位于同一水平极线上，降低匹配搜索复杂度；
4. **立体匹配**：沿极线搜索左右图对应点，计算视差图，进而生成深度/点云。

OpenCV 的标定流程基于棋盘格角点检测（`findChessboardCorners`、`cornerSubPix` 做亚像素细化），再由 `calibrateCamera` 与双目标定接口完成。标定板需在测量体积内多个位置成像，保证覆盖整个视场。

### 3. 系统硬件与安装要点

| 环节 | 要点 |
|------|------|
| 基线长度 | 决定深度精度的量程特性，基线越大、近距精度越高、量程越受限 |
| 两相机同步 | 快门需同步或目标静止，避免运动造成左右失配 |
| 温度/机械稳定性 | 双相机相对位姿变化会引入深度漂移 |
| 纹理 | 无明显纹理区域匹配困难，可配合图案投射或选用其他 3D 技术 |

### 4. 深度计算与点云输出

视差图 d、焦距 f、基线 B 与深度 Z 的关系（理想平行配置）：

```
Z = f × B / d
```

深度图经反投影可转换为三维点云，供后续点云处理（如 PCL 配准/分割）与机器人引导使用。实际系统深度误差通常随距离增大而增大。

### 5. 验证与常见问题

| 现象 | 原因与对策 |
|------|------------|
| 深度整体偏移 | 标定误差，重标定并检查板面平整 |
| 边缘处深度噪声大 | 遮挡/失配，优化相机布局与匹配参数 |
| 纹理少区域空洞 | 增加图案灯光或换技术 |
| 安装后精度变差 | 重新双目标定，固定两相机 |

验收：用已知距离的目标验证深度误差在应用公差内；深度/点云在目标移动范围内稳定。
