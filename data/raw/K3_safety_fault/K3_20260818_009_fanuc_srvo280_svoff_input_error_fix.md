# FANUC SRVO-280 SVOFF 输入故障指南

- 来源 URL：[FANUC R-30iB Controller Maintenance Manual B-83195EN/07](https://ysprojectcrew.helpmecdh.com/Manuals/PDFs/Robotics/RJ30ibcontrollermaintenancemanual.pdf)
- 作者/机构：FANUC Corporation；本文由 XH-agent 基于维护手册二次整理
- 发布日期：维护手册版本 B-83195EN/07；本文整理日期 2026-08-18
- 权威等级：A（FANUC 原厂维护手册）
- 领域标签：K3_安全规范、K3_故障诊断
- 摘要：解析 FANUC SRVO-280（SVOFF input）的含义与排查路径，覆盖 EGS1-EGS11/EGS2-EGS21 双通道伺服关闭输入、外部回路检查、急停板处理和安全复机要求，明确禁止在使用 SVOFF 安全功能的系统中旁路信号。

## 正文

> 本文是对 FANUC 维护手册的中文归纳，不是手册逐字原文。SVOFF 属于安全相关输入，端子、信号极性和时序必须以当前控制柜电气图为准。

### 1. 故障代码概述

| 字段 | 内容 |
| --- | --- |
| 故障代码 | SRVO-280 |
| 故障名称 | SVOFF input |
| 手册定义 | 接入急停板的外部 SVOFF 触点处于断开状态。R-30iB 手册以 EGS1-EGS11 或 EGS2-EGS21 为示例。 |
| 主要影响 | 伺服关闭条件被触发，机器人无法按正常条件运行。 |
| 关联安全功能 | 外部伺服关闭、产线安全 PLC/继电器及急停板安全输入。 |

### 2. 常见原因分析

1. **外部 SVOFF 回路确实打开**
   - 产线安全 PLC、维护开关或外部伺服关闭触点发出了停机请求。
   - 设备处于维护、换型或异常停机状态，回路打开是设计行为。

2. **EGS 双通道接线或连接器故障**
   - EGS1-EGS11 与 EGS2-EGS21 中一路断开、接触不良或电缆损伤。
   - 安全继电器触点烧蚀、端子松动、线缆压伤或屏蔽处理错误。

3. **安全 PLC/继电器时序或逻辑不一致**
   - 两个安全通道的动作时序不满足设备要求，可能进一步引发 SRVO-268/269 等状态异常。
   - 不能把普通 PLC 输出当作满足安全功能的替代品，必须确认原设计的安全控制架构。

4. **急停板故障**
   - 在外部回路和连接确认正常后，手册将急停板列为后续维修对象。

### 3. 故障诊断流程

```text
发生 SRVO-280 / SVOFF input
    ↓
1. 保持机器人安全停机，确认是否存在有效的产线停机请求
   → 查看安全 PLC/继电器诊断状态和相关报警历史
    ↓
2. 对照本机电气图确认 EGS 双通道接线
   → 核对 EGS1-EGS11、EGS2-EGS21 的端子、连接器和电缆
    ↓
3. 检查外部安全回路
   → 检查安全 PLC 输出、继电器触点、维护开关和接线盒
   → 确认两路动作和返回时序符合设计
    ↓
4. 修复断线、松脱或失效的安全元件
   → 不能用普通 I/O 强制置位替代安全回路恢复
    ↓
5. 外部回路确认正常但报警持续
   → 由授权人员按手册检查急停板
    ↓
6. 安全功能验证后复机
   → 分别验证 SVOFF 动作、恢复条件、急停和模式切换
```

### 4. 处理方法

**外部回路检查：**

1. 记录 SRVO-280 是否与 SRVO-268、SRVO-269、SRVO-230/231 或产线安全 PLC 报警同时发生。
2. 依据本机柜型图纸确认 EGS 双通道端子和信号来源。R-30iB A/B 柜端子块编号可能不同，不能照搬其他型号的接线。
3. 在安全隔离后检查外部回路的触点状态、继电器输出、连接器、线缆连续性和端子紧固。对安全 PLC 的诊断应由其制造商手册和安全程序共同约束。
4. 修复后执行两路独立动作测试：触发 SVOFF 时机器人应停机；释放触发条件后，只有在所有安全许可满足时才能恢复伺服。

**安全边界：**

- 如果系统使用 SVOFF 信号，禁止通过短接 EGS1-EGS11 或 EGS2-EGS21 的方式“消除”报警。
- 即使某些机型手册对未使用信号给出了原始配置连接说明，也不能把它用于已经配置安全功能的生产单元；任何变化都要经过风险评估、图纸审批和安全验证。
- 不得用软件强制、普通 DI/DO 映射或屏蔽报警代替双通道安全回路。

**复机流程：**

1. 产线安全负责人确认停机原因已经解除。
2. 在低风险条件下测试 SVOFF 触发、两路一致性、伺服关闭、急停和安全门/围栏联锁。
3. 首次自动运行采用低速或空载试运行，确认机器人和工装无异常后再恢复正式节拍。

### 5. 预防措施

1. 将 EGS 双通道安全输入、继电器触点和安全 PLC 输出纳入周期功能测试。
2. 对换型、设备改造和安全 PLC 程序变更建立接线图、逻辑版本和验证记录。
3. 重点检查门锁、线槽、拖链和接线盒处的线缆弯折、拉力和端子松脱。
4. 维护人员应区分 SVOFF 输入、围栏输入和急停链错误，避免错误复位或错误改线。

## 适用场景
