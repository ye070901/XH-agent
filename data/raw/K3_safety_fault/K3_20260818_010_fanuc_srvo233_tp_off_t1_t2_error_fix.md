# FANUC SRVO-233 示教器 T1/T2 报警指南

- 来源 URL：[FANUC R-30iB Controller Maintenance Manual B-83195EN/08](https://studylib.net/doc/27459949/r-30ib-controller-maintenance-manual-b-83195en-08-4-pdf-free)

- 发布日期：维护手册版本 B-83195EN/08；本文整理日期 2026-08-18
- 权威等级：A（FANUC 原厂维护手册）
- 领域标签：K3_安全规范、K3_故障诊断
- 摘要：解析 FANUC SRVO-233（TP OFF in T1, T2）的触发条件，区分示教器未启用、控制柜门打开、模式开关和硬件链路问题，并给出 T1/T2 示教与 AUTO 自动模式下的安全检查和复机步骤。

## 正文

> 本文是对 FANUC 维护手册的中文归纳，不是手册逐字原文。T1/T2 和 AUTO 是不同的安全工作模式，模式切换必须由受训人员按现场安全程序执行。

### 1. 故障代码概述

| 字段 | 内容 |
| --- | --- |
| 故障代码 | SRVO-233 |
| 故障名称 | TP OFF in T1, T2 |
| 手册定义 | 在 T1 或 T2 模式下，示教器处于禁用状态；部分 R-30iB 版本同时将控制柜门打开列为触发条件。 |
| 主要影响 | 示教操作不能按安全条件进行，机器人不会进入正常的手动伺服许可状态。 |
| 关键对象 | 示教器 Enable 状态、模式开关、控制柜门、安全链、示教器电缆及相关控制板。 |

### 2. 常见原因分析

1. **示教器被设为 Disable**
   - T1/T2 是示教模式，要求示教器处于允许操作的状态。
   - 维护、换型或交接后，示教器开关可能仍保持禁用。

2. **模式开关与操作意图不一致**
   - 如果要进行示教，应使用 T1/T2 并启用示教器；如果要进行自动运行，应将模式置于 AUTO，并满足自动运行的全部安全条件。
   - 不应通过错误模式切换来绕开报警。

3. **控制柜门打开**
   - 某些 R-30iB 版本把柜门状态纳入 SRVO-233 触发逻辑。
   - 柜门未关好、门开关未动作或门开关电缆异常，都可能导致报警持续。

4. **硬件或连接异常**
   - 手册的后续处理方向包括示教器、示教器电缆、模式开关、急停板及六轴伺服放大器。
   - 在替换板卡前应先完成模式、门状态和电缆连接的基本检查。

### 3. 故障诊断流程

```text
发生 SRVO-233 / TP OFF in T1, T2
    ↓
1. 确认现场操作目的
   → 示教/手动：模式应为 T1 或 T2，并启用示教器
   → 自动生产：模式应为 AUTO，并满足自动安全许可
    ↓
2. 若处于 T1/T2，检查示教器 Enable 状态
   → 确认示教器开关、Deadman 和急停状态符合本机安全程序
    ↓
3. 检查控制柜门
   → 若当前版本将柜门纳入该报警，确认门已关闭且门开关可靠
    ↓
4. 检查模式开关、示教器电缆与伴随报警
   → 记录报警历史，区分模式信号、门开关和示教器链路问题
    ↓
5. 修复外部状态或连接问题后复位
   → 若仍存在，由授权人员按手册检查示教器、急停板和伺服放大器
    ↓
6. 受控验证
   → T1/T2 做低速手动验证；AUTO 做无人员在危险区的自动许可验证
```

### 4. 处理方法

**示教模式：**

1. 将模式开关置于现场安全程序规定的 T1 或 T2，确认人员在规定位置并握持使能装置。
2. 在示教器上启用 Teach Pendant；若示教器具备 Enable/Disable 开关，应确认状态为允许示教。
3. 确认示教器急停已释放、Deadman 按钮按在中间允许位置，并检查是否有其他安全报警。
4. 关闭控制柜门（若本控制器版本将其作为示教许可条件），再执行报警复位和低速点动测试。

**自动模式：**

1. 不要在 T1/T2 中强行启动自动程序。将模式按产线程序切换到 AUTO，并确认示教器、安全门、急停、外部启动许可和安全 PLC 条件全部满足。
2. 若切换到 AUTO 后仍有 SRVO-233，检查模式开关和柜门状态，不要以软件强制输入替代安全条件。

**硬件升级处理：**

- 若 Enable 状态、模式开关、柜门和电缆均正常，仍持续报警，按机型手册顺序检查/更换示教器、示教器电缆、模式开关、急停板和六轴伺服放大器。
- 更换板卡前完成控制器完整备份，并记录原有系统配置；更换后执行安全功能测试和受控复机。

### 5. 预防措施

1. 在换型、程序维护和交接班检查中明确记录当前模式、示教器 Enable 状态和柜门状态。
2. 定期检查示教器电缆拖拽、插头锁紧、急停按钮、Deadman 开关和模式开关机械手感。
3. 对 T1/T2 与 AUTO 的模式切换设置授权和记录流程，避免人员在错误模式下处理报警。
4. 在控制柜维修后验证：T1/T2 能安全示教，AUTO 能在危险区无人且互锁满足时运行，模式切换不会产生未预期的伺服许可。

## 适用场景

本文可用于 XH-agent 的示教器故障分诊、T1/T2 与 AUTO 模式切换检查、换型复机及安全操作规程培训。不同 FANUC 控制器的软件版本可能将柜门状态归入不同报警，现场应以实际报警文本和对应手册为准。
