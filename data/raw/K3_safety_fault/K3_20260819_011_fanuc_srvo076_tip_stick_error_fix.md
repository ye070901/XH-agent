## 正文

> 本文是对 FANUC 维护手册的中文归纳，不是手册逐字原文。涉及抱闸释放、动力电缆和伺服放大器的操作必须由受训人员执行，并采取防坠落和残压防护措施。

### 1. 故障代码概述

| 字段 | 内容 |
| --- | --- |
| 故障代码 | SRVO-076 |
| 故障名称 | Tip Stick Detection |
| 手册定义 | 伺服软件在启动时判断存在过大的扰动；检测到异常负载，原因可能与焊接过程有关。 |
| 主要影响 | 机器人伺服停止或无法启动，可能伴随工装干涉、碰撞、负载超限或动力链路异常。 |
| 诊断原则 | 先排除真实机械负载/碰撞，再检查参数、抱闸、电源和电气部件。 |

### 2. 常见原因分析

1. **机器人碰撞或工装干涉**
   - 焊枪、夹具、工件或机器人本体发生碰撞，导致启动时扰动转矩异常。
   - 焊接飞溅、枪头粘连或工件未释放也可能造成 Tip Stick 类异常。

2. **机械负载增加**
   - 减速机、轴承、外部轴、软管包或工装发生卡滞。
   - 现场负载已超过机械单元或伺服轴额定范围。

3. **负载参数设置不正确**
   - 工具重量、重心、惯量或负载组参数与实际工装不一致。
   - 换型后仍使用上一套工装的负载设置。

4. **抱闸或供电异常**
   - 对应轴抱闸未正常释放，或抱闸回路连接异常。
   - 控制器输入电压或变压器设置不符合规格，导致可用转矩不足。

5. **伺服动力链路故障**
   - 伺服放大器、对应伺服电机、机器人连接动力电缆或机械臂内部动力/抱闸电缆异常。

### 3. 故障诊断流程

```text
发生 SRVO-076 / Tip Stick Detection
    ↓
1. 停止自动运行并确认机器人、工件、焊枪和夹具状态
   → 先排除碰撞、粘连、卡滞和工装干涉
    ↓
2. 检查对应轴的机械负载
   → 手动确认无异常阻力、软管包未拉紧、工装未超载
    ↓
3. 核对负载设置和换型数据
   → 检查重量、重心、惯量与当前工具/工件是否一致
    ↓
4. 检查抱闸和控制器电源条件
   → 确认抱闸动作、输入电压及变压器设置符合设备要求
    ↓
5. 若故障仍在，按轴号检查电气部件
   → 伺服放大器 → 伺服电机 → 机器人动力电缆 → 内部动力/抱闸电缆
    ↓
6. 低速、空载受控验证
   → 根因排除后先执行单轴低速测试，再恢复工艺节拍
```

### 4. 处理方法

1. **碰撞/干涉处理**：确认机器人姿态和工装状态，解除粘连或卡滞，检查碰撞造成的机械变形；不要仅复位报警后继续自动运行。
2. **负载处理**：核对当前工具、工件和换型程序的负载参数。参数修改应基于实际测量或经过验证的工艺数据，不能通过放宽保护阈值掩盖机械问题。
3. **抱闸处理**：检查对应轴抱闸释放和保持功能。需要释放抱闸时，必须支撑可能下落的轴并遵循机械单元手册。
4. **电气处理**：检查控制器输入电压与变压器设置；若故障跟随某轴，按手册顺序检查伺服放大器、伺服电机、机器人连接动力电缆和内部电缆。
5. **复机验证**：先断开工艺负载或采用安全空载条件进行低速点动，确认无异常噪声、温升、振动和位置偏差，再逐步恢复速度和产线节拍。

### 5. 预防措施

1. 换型时同步更新工具、工件和负载组参数，并在首件前执行低速验证。
2. 定期检查焊枪、夹具、软管包和外部轴的机械干涉、磨损与卡滞。
3. 维护抱闸、动力电缆和伺服放大器时记录轴号、故障历史和更换部件，便于判断故障是否随部件转移。
4. 对反复出现的 SRVO-076，优先查机械负载和工艺条件，不应通过降低碰撞保护或修改伺服参数消除报警。
