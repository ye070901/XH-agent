# FANUC SRVO-004 安全围栏报警处理指南

- 来源 URL：[R-30iB Controller Maintenance Manual B-83195EN/08](https://studylib.net/doc/27459949/r-30ib-controller-maintenance-manual-b-83195en-08-4-pdf-free)
- 作者/机构：FANUC Corporation；本文由 XH-agent 基于维护手册二次整理
- 发布日期：维护手册版本 B-83195EN/08；本文整理日期 2026-08-12
- 权威等级：A（FANUC 原厂维护手册）
- 领域标签：K3_安全规范、K3_故障诊断
- 摘要：说明 FANUC SRVO-004（Fence open，安全围栏打开）的安全含义、排查顺序和复机验证要求。重点是确认安全门/围栏双通道回路、模式开关及急停板状态，禁止以短接或旁路安全信号代替故障修复。

## 正文

> 本文是对 FANUC 维护手册的中文归纳，不是手册逐字原文。端子名称、柜型和接线方式会因控制器版本而不同，现场必须以本机电气图和授权手册为准。

### 1. 故障代码概述

| 字段 | 内容 |
| --- | --- |
| 故障代码 | SRVO-004 |
| 故障名称 | Fence open（安全围栏打开） |
| 手册定义 | 在自动模式下，接入安全围栏的安全触点处于断开状态。 |
| 主要影响 | 机器人不能按自动运行条件使能伺服，属于工作单元人员防护链路的一部分。 |
| R-30iB 参考信号 | 手册使用 EAS 双通道安全围栏输入；具体端子随 A/B 控制柜和机型变化。 |

### 2. 常见原因分析

1. **安全门或围栏实际处于打开状态**
   - 人员进入工作单元后安全门尚未完全关合，或门锁未达到安全开关的动作位置。
   - 机械门变形、锁扣磨损、门铰链下沉也会造成“门已关但开关未动作”。

2. **安全开关、门锁或现场电缆故障**
   - 双通道安全开关的一路或两路触点异常。
   - 电缆在门铰链、线槽或接线盒处被拉伤、松脱或接触不良。

3. **模式开关或安全回路配置异常**
   - FANUC 手册要求在围栏与电缆检查后核对模式开关。
   - 改造、换柜或恢复接线后，安全回路可能与本机电气图不一致。

4. **急停板异常或伴随故障**
   - 手册将急停板列为后续检查/更换对象。
   - 若同时出现 SRVO-213，手册提示可能涉及急停板 FUSE2 熔断，应按该报警的专用流程处理。

### 3. 故障诊断流程

```text
发生 SRVO-004 / Fence open
    ↓
1. 保持机器人停机，确认危险区无人后再关闭安全门
   → 不得复位、强制输出或旁路安全信号
    ↓
2. 检查安全门、围栏和门锁的实际机械状态
   → 门是否完全关闭？锁舌是否可靠啮合？门体是否有变形或干涉？
    ↓
3. 使用批准的安全回路图检查双通道安全开关及电缆
   → 核对两个安全通道的连续性、插接状态和线缆损伤
   → 维修后应恢复原安全等级的元件与接线方式
    ↓
4. 核对控制器模式开关与相关报警
   → 检查模式开关操作、连接和伴随的 SRVO 安全链报警
    ↓
5. 若外围回路正常但报警持续
   → 由授权维修人员按本机手册诊断急停板及相关连接
    ↓
6. 完成安全功能验证后受控复机
   → 分别测试开门停机、关门许可、急停和模式切换
   → 先低风险受控启动，再交还自动生产
```

### 4. 处理方法

**现场处理：**

1. 清点人员、关闭安全门并确认门锁机械状态正常；不要仅凭肉眼确认门已关闭。
2. 按经批准的电气图检查安全门开关及其双通道电缆。损坏元件应使用满足原设计安全等级的替代件，并完成接线复核。
3. 若安全门已关闭且外部线路正常，检查模式开关状态、急停板连接和伴随报警；需要板卡级维修时应由具备授权的人员执行。

**安全复机要求：**

1. 维修完成后，在机器人无法造成伤害的受控条件下，逐项验证：开门后伺服/自动运行被抑制，关门并满足系统许可后才可恢复；急停与模式切换也必须分别有效。
2. 安全功能测试应写入维修或复机记录，记录故障根因、更换部件、测试人和测试结果。
3. 若现场原本不使用围栏输入，只能依据该设备经过批准的原始设计和电气图确认配置。不得把“未使用信号”的说明用于已配置安全围栏的工作单元。

**严禁做法：**

- 禁止为了恢复产能而短接、跨接、软件屏蔽或强制安全门/围栏信号。
- 禁止在未完成人员清点和安全功能测试前，使能伺服或恢复自动模式。
- 禁止套用其他 FANUC 控制器的端子号或安全接线图；不同柜型的端子定义可能不同。

### 5. 预防措施

1. 将门锁、门铰链、安全开关、接线盒和随动电缆纳入周期点检，尤其检查高频开关门位置的机械磨损和线缆弯折。
2. 任何围栏、安全门、PLC 或控制柜改造均应更新电气图、风险评估和安全功能验证记录。
3. 建立异常复机清单：安全门关闭、危险区无人、急停有效、模式正确、报警清除和受控试运行缺一不可。
4. 对 SRVO-004 与 SRVO-266/267 等安全链相关报警建立关联查询，防止只消除表面报警而遗漏双通道失配。
