# FANUC SRVO-134 直流母线低压指南

- 来源 URL：[R-30iB Controller Maintenance Manual B-83195EN/08](https://studylib.net/doc/27817886/b-83195en)
- 作者/机构：FANUC Corporation；本文由 XH-agent 基于维护手册二次整理
- 发布日期：维护手册版本 B-83195EN/08；本文整理日期 2026-08-19
- 权威等级：A（FANUC 原厂维护手册）
- 领域标签：K3_故障诊断、K3_产线适配
- 摘要：解析 FANUC SRVO-134（DCLVAL）主回路直流母线电压异常低的原因和处理顺序，覆盖瞬时掉电、输入电压、变压器设置、机器人与辅助轴同时加速以及急停单元/伺服放大器检查，适用于上电或运行中伺服掉电诊断。

## 正文

> 本文是对 FANUC 维护手册的中文归纳，不是手册逐字原文。直流母线和伺服放大器存在危险残压，测量、放电和拆线必须由合格电气人员按控制器维修程序执行。

### 1. 故障代码概述

| 字段 | 内容 |
| --- | --- |
| 故障代码 | SRVO-134 |
| 故障名称 | DCLVAL alarm |
| 手册定义 | 伺服放大器主回路电源的直流母线电压异常低。 |
| 主要影响 | 伺服可能关闭，机器人停止运行或无法建立稳定的伺服电源。 |
| 重点方向 | 瞬时电源中断、输入电压、变压器设置、负载/加速条件及电源/伺服部件。 |

### 2. 常见原因分析

1. **瞬时电源中断或电源波动**
   - 现场电源短时跌落、接触器抖动、相位缺失或上级配电切换可能导致直流母线低压。

2. **输入电压或变压器设置不正确**
   - 控制器输入电压低于设备要求，或变压器一次侧选择与实际电源不匹配。

3. **运行条件过重**
   - 机器人或辅助轴在高负载、高加速度条件下运行，电源系统无法维持母线电压。
   - 某些系统中机器人和辅助轴同时加速会增加电源瞬态需求。

4. **急停单元或伺服放大器异常**
   - 在外部电源和运行条件确认正常后，急停单元、六轴伺服放大器或电源单元可能需要进一步诊断。

### 3. 故障诊断流程

```text
发生 SRVO-134 / DCLVAL
    ↓
1. 记录报警时刻、运行程序、机器人/辅助轴状态和报警历史
    ↓
2. 检查是否发生瞬时掉电、相位缺失或接触器抖动
   → 对照产线电源监控和同一时刻其他设备报警
    ↓
3. 由合格电气人员检查控制器输入电压和变压器设置
   → 必须按控制器额定规格和电气安全程序测量
    ↓
4. 评估运行条件
   → 降低验证速度/负载，确认是否存在机器人与辅助轴同时高动态动作
    ↓
5. 若外部电源与工艺条件正常而报警持续
   → 按手册检查急停单元、伺服放大器及相关电源部件
    ↓
6. 受控复机
   → 空载低速运行，再逐步恢复负载和生产节拍
```

### 4. 处理方法

1. **电源事件处理**：确认上级配电、断路器、接触器、相位和瞬时电压记录。若存在电源质量问题，先修复供电再复位机器人。
2. **输入与变压器处理**：按控制器型号核对输入电压范围和变压器设置。不得在未确认额定值时调整抽头或修改参数。
3. **运行条件处理**：降低机器人或辅助轴的加速度、负载或占空比进行验证；若机器人与辅助轴同时加速触发报警，应重新规划动作时序或分配动态负载。
4. **部件处理**：外部电源、设置和运行条件均正常时，由授权维修人员按手册检查/更换急停单元、伺服放大器或相关电源部件。
5. **复机验证**：记录复位前后的电源和负载条件，先执行空载低速程序，再逐步恢复工艺速度，观察报警是否重现。

### 5. 预防措施

1. 对机器人控制柜输入电压、相位、变压器设置和接触器状态进行周期检查。
2. 对机器人与辅助轴的同步动作做峰值负载评估，避免多个大惯量轴同时高加速。
3. 在产线电源切换、焊机启动和大功率设备投入时监测瞬时电压事件。
4. 不得通过降低保护阈值、屏蔽报警或反复上电掩盖母线低压根因。
