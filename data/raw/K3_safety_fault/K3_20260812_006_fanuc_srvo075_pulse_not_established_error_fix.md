# FANUC SRVO-075 脉冲未建立处理指南

- 来源 URL：[R-30iB Controller Maintenance Manual B-83195EN/08](https://studylib.net/doc/25971285/466336655-r-30ib-controller-maintenance-manual-b-83195en-08)
- 作者/机构：FANUC Corporation；本文由 XH-agent 基于维护手册二次整理
- 发布日期：维护手册版本 B-83195EN/08；本文整理日期 2026-08-12
- 权威等级：A（FANUC 原厂维护手册）
- 领域标签：K3_故障诊断
- 摘要：说明 FANUC SRVO-075（Pulse not established，脉冲未建立）的含义和恢复操作。该报警表示控制器尚不能建立脉冲编码器绝对位置；应在安全条件下复位并以低速点动报警轴，若重复出现则停止复机并按关联报警和机型手册进一步检修。

---

## 正文

> 本文是对 FANUC 维护手册的中文归纳，不是手册逐字原文。点动、标定和编码器维修会影响机器人位置可信度，必须由受训人员在受控环境下执行。

### 1. 故障代码概述

| 字段 | 内容 |
| --- | --- |
| 故障代码 | SRVO-075 |
| 故障名称 | Pulse not established（脉冲未建立） |
| 手册定义 | 无法建立脉冲编码器的绝对位置。 |
| 手册动作 | 复位报警后，点动发生报警的轴，直至相同报警不再出现。 |
| 主要影响 | 报警轴的位置建立尚未完成；在位置和安全条件未验证前，不得直接恢复自动运行。 |

### 2. 诊断要点

1. **先确认是 SRVO-075 本体还是关联报警**
   - R-30iB 手册中，SRVO-097（轨道编码器 Pulse not established）引用 SRVO-075 的处理逻辑，但其对象可能是外部轴/轨道编码器。
   - 记录组号、轴号和同时出现的 SRVO 报警，避免把外部轴问题当作机器人本体轴问题。

2. **确认是否处于安全的点动条件**
   - 点动前应确认危险区无人、工具与工装无干涉、机器人姿态可预测。
   - 示教模式、使能装置、速度限制和现场许可应满足本机安全程序。

3. **不把“报警消失”当作全部维修结论**
   - SRVO-075 的官方恢复动作是让该轴产生足够运动以建立脉冲位置；这不等于允许忽略同时存在的电池、编码器、通讯或标定报警。
   - 如果报警重复出现，应停止重复复位，转查报警历史和对应控制器/机械单元维护手册。

4. **关注位置恢复后的验证**
   - 即使 SRVO-075 消失，也应确认机器人姿态、程序点和安全区域逻辑可信，再考虑自动运行。
   - 若近期更换过脉冲编码器或发生 SRVO-062、SRVO-038，可能还需要执行对应的 MASTERING 流程。

### 3. 故障诊断流程

```text
发生 SRVO-075 / Pulse not established
    ↓
1. 记录报警组号、轴号、控制器型号和同时报警
   → 区分机器人本体轴与轨道/外部轴
    ↓
2. 进入受控的示教/手动操作条件
   → 确认危险区无人、低速限制有效、工具与工装无干涉
    ↓
3. 复位 SRVO-075
    ↓
4. 以最低可行速度点动报警轴
   → 仅在可观察、可立即停止的方向和行程内操作
   → 点动至相同报警不再出现
    ↓
5. 若报警消失
   → 检查当前姿态和关联报警
   → 低速验证必要的运动，确认位置可信后再进行后续复机
    ↓
6. 若报警再次出现或无法安全点动
   → 停止自动复机
   → 依据关联报警、编码器状态和机型手册升级诊断
```

### 4. 处理方法

**标准恢复操作：**

1. 由具备机器人操作资格的人员切换到经批准的手动/示教状态，确认现场安全条件和观察范围。
2. 在安全停止位置复位报警；不要在视线受阻、工具接近夹具或人员仍可能进入单元时点动。
3. 以低速点动报警轴。FANUC 手册的目标是让相同 SRVO-075 不再出现，而不是要求在未知姿态下完成任意大幅运动。
4. 报警消失后，检查报警历史和当前机械姿态；若同时有 SRVO-062、SRVO-038 或编码器故障，应先按相应文档处理，再决定是否标定和复机。

**何时停止并升级处理：**

- 点动后 SRVO-075 立即再次出现。
- 无法确认报警轴、无法安全观察运动，或机器人位置与工艺基准不可信。
- 同时出现电池备份、脉冲编码器数据传输、脉冲不匹配等报警。
- 近期发生过编码器更换、机械移动、碰撞或控制器数据恢复。

上述情形不应靠重复复位解决，应保存报警信息，并由维修人员依据适用机械单元手册检查编码器及绝对位置恢复路径。

### 5. 预防措施

1. 建立编码器、电池、主板备份恢复和标定作业的变更记录，使 SRVO-075 出现时可快速追溯近期操作。
2. 对外部轴、轨道轴和机器人本体轴分别维护轴号映射和安全点动范围，避免错误点动相邻轴。
3. 在机器人附近设置可观察的点动区域和明确的人员隔离程序，确保位置恢复操作始终处于低速、受控状态。
4. 对频繁出现 SRVO-075 的设备，按机型手册排查关联的绝对位置、脉冲编码器和通讯报警，不以临时复位替代根因维护。

## 适用场景

本文可用于 XH-agent 的编码器位置建立报警分流、示教阶段恢复指引和低速复机检查。它与 SRVO-062、SRVO-038 互补：SRVO-075 解决“脉冲位置尚未建立”的当前状态，SRVO-062 与 SRVO-038 则可能要求进一步恢复绝对位置或重新标定。
