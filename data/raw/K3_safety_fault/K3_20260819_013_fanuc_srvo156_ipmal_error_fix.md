# FANUC SRVO-156 伺服过流故障指南

- 来源 URL：[R-30iB Controller Maintenance Manual B-83195EN/07](https://ysprojectcrew.helpmecdh.com/Manuals/PDFs/Robotics/RJ30ibcontrollermaintenancemanual.pdf)

- 权威等级：A（FANUC 原厂维护手册）
- 领域标签：K3_故障诊断
- 摘要：解析 FANUC SRVO-156（IPMAL）伺服放大器主回路过流故障，给出断电隔离、断开动力电缆与抱闸电缆、防止轴意外下落、绝缘检查和 U/V/W 相间电阻判断流程，适用于伺服上电或运行瞬间过流停机。

## 正文

> 本文是对 FANUC 维护手册的中文归纳，不是手册逐字原文。伺服放大器直流母线和电机动力端存在危险电压；断电、残压确认、拆线和抱闸防坠必须由合格电气/机械人员执行。

### 1. 故障代码概述

| 字段 | 内容 |
| --- | --- |
| 故障代码 | SRVO-156 |
| 故障名称 | IPMAL alarm |
| 手册定义 | 伺服放大器主回路流过异常高电流。 |
| 主要影响 | 伺服放大器保护动作，机器人停止运动或无法建立伺服。 |
| 重点对象 | 六轴伺服放大器、对应轴动力电缆、伺服电机及 U/V/W/GND 绝缘。 |

### 2. 常见原因分析

1. **动力电缆短路或对地故障**
   - U、V、W 相间短路，或动力线与 GND 绝缘损坏。
   - 机器人连接动力电缆在拖链、底座或柜内受到挤压和磨损。

2. **伺服电机绕组异常**
   - 电机绕组相间不平衡或绝缘降低，导致放大器检测到过流。

3. **伺服放大器功率模块故障**
   - 断开外部动力电缆后仍立即出现报警，可能是放大器内部功率回路异常。

4. **机械故障导致的异常电流**
   - 机械卡滞、碰撞或抱闸未释放可能使电机在启动时承受异常负载；应结合 SRVO-076 等关联报警判断。

### 3. 故障诊断流程

```text
发生 SRVO-156 / IPMAL
    ↓
1. 记录组号、轴号、发生时刻和伴随报警
   → 停止重复上电，防止扩大功率回路损伤
    ↓
2. 关闭主电源并执行锁定挂牌
   → 等待并确认直流母线残压处于允许的安全值
    ↓
3. 断开报警伺服放大器的动力电缆
   → 同时按手册断开对应抱闸电缆，防止轴意外下落
    ↓
4. 受控重新上电验证放大器侧故障
   → 若断开动力电缆后仍立即报警，优先怀疑伺服放大器
    ↓
5. 断电后检查动力线绝缘
   → 检查 U/V/W 与 GND 是否短路或绝缘异常
    ↓
6. 检查 U-V、V-W、W-U 三组相间电阻
   → 三组明显不一致时，继续区分电机或动力电缆故障
    ↓
7. 更换故障部件并低速验证
   → 先空载单轴测试，再恢复多轴和自动生产
```

### 4. 处理方法

1. **安全隔离**：主电源关闭后执行锁定挂牌，等待并测量残压。不得仅凭面板熄灭判断放大器已无电。
2. **防止轴下落**：按照维护手册断开动力电缆时，同时处理对应抱闸电缆并支撑可能下落的轴；机械单元型号不同，支撑方式须按其手册执行。
3. **放大器分离判断**：在动力电缆和抱闸电缆按规定断开后进行受控验证。如果报警仍然出现，手册建议更换伺服放大器。
4. **绝缘检查**：断电状态下检查动力电缆 U、V、W 与 GND；发现短路或绝缘异常时更换动力电缆，不得带故障试运行。
5. **相间电阻检查**：用适合的低阻测量方法比较 U-V、V-W、W-U 三组电阻。若三组不一致，应进一步检查伺服电机和动力电缆，并按部件维修规范更换。
6. **复机验证**：更换后先进行单轴、低速、空载测试，确认无 IPMAL、异常声音、发热和机械卡滞，再恢复工艺负载。

### 5. 预防措施

1. 定期检查机器人动力电缆、柜内端子、拖链弯曲段和电机接头，避免绝缘层磨损。
2. 维护前记录报警轴号、动力电缆编号、电机型号和放大器型号，防止错接和错换。
3. 对反复出现的过流报警，结合机械卡滞、抱闸状态、碰撞和负载参数综合诊断，不应通过提高电流限制规避保护。
4. 伺服放大器更换和动力线绝缘测试完成后，必须执行安全复机及首件低速验证。
