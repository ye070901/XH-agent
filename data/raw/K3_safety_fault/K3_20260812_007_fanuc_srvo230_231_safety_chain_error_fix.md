# FANUC SRVO-230/231 安全链失配处理指南

- 来源 URL：[R-30iB Controller Maintenance Manual B-83195EN/08](https://studylib.net/doc/27459949/r-30ib-controller-maintenance-manual-b-83195en-08-4-pdf-free)

- 发布日期：维护手册版本 B-83195EN/08；本文整理日期 2026-08-12
- 权威等级：A（FANUC 原厂维护手册）
- 领域标签：K3_安全规范、K3_故障诊断
- 摘要：解析 FANUC SRVO-230/231（双通道安全链失配）的报警含义、伴随报警定位、根因修复和专用复位边界。该类报警意味着冗余安全信号状态不一致，必须先修复故障，再按控制器专用 Chain Error Reset 流程复位。

## 正文

> 本文是对 FANUC 维护手册的中文归纳，不是手册逐字原文。安全链失配会降低冗余安全功能的完整性，禁止将本文当作安全回路改造或旁路接线依据。

### 1. 故障代码概述

| 字段 | 内容 |
| --- | --- |
| 故障代码 | SRVO-230 / SRVO-231 |
| 故障名称 | Chain 1 abnormal / Chain 2 abnormal（安全链 1 / 2 异常） |
| 手册定义 | 两路冗余安全信号出现状态不一致。 |
| SRVO-230 条件 | 第 1 链对应触点闭合而第 2 链对应触点断开。 |
| SRVO-231 条件 | 第 1 链对应触点断开而第 2 链对应触点闭合。 |
| 主要影响 | 单一安全通道已可能失效；在另一通道故障时，安全功能可能无法保证。 |

### 2. 诊断要点

1. **从伴随报警识别具体安全信号**
   - R-30iB 手册要求查看同时发生的报警，以确定哪一路信号失配。
   - SRVO-266 至 SRVO-275、SRVO-370 至 SRVO-385 可与链错误同时出现，应按对应条目排查具体的围栏、外部急停、伺服关闭或其他安全输入。

2. **理解双通道不是“双倍普通输入”**
   - 手册以 EES（外部急停）、EAS（围栏）和 EGS（伺服关闭）等双通道信号为例。
   - 两路不同步可能来自安全开关、继电器/安全 PLC、接线、电缆、连接器或急停板；必须依已批准的安全回路图定位。

3. **普通复位与 Chain Error Reset 不可混用**
   - 手册说明链错误状态由软件保持；根因修复后，需执行专用 Chain Error Reset。
   - 在完成专用复位前执行普通复位，可能显示 SRVO-237（Chain error cannot be reset）。

4. **复位前必须完成根因修复**
   - FANUC 明确警告：若一条冗余回路仍故障就继续使用机器人，另一回路再故障时安全性可能无法保证。

### 3. 故障诊断流程

```text
发生 SRVO-230 或 SRVO-231
    ↓
1. 保持安全停机并禁止普通复位
   → 不旁路、不短接、不强制安全信号
    ↓
2. 在示教器 ALARM/HIST 中记录报警历史和伴随报警
   → 确定具体属于 EES、EAS、EGS、NTED 或其他双通道信号
    ↓
3. 按本机认可的电气图检查对应安全回路
   → 检查安全开关/门锁、急停按钮、安全 PLC/继电器、端子、连接器和电缆
   → 检查两路信号是否满足本机规定的时序和一致性要求
    ↓
4. 修复根因并完成安全功能验证
   → 验证两路输入均按设计切换，且停机响应符合风险评估
    ↓
5. 执行控制器专用 Chain Error Reset
   → 仅由授权人员依对应控制器菜单进行
    ↓
6. 清除报警后进行受控复机
   → 再次验证急停、围栏/门锁、模式切换等相关安全功能
   → 通过复机记录审核后恢复生产
```

### 4. 处理方法

**根因处理：**

1. 先读取报警历史。R-30iB 的标准路径为在示教器进入 `ALARM` 后选择 `HIST`，获取 SRVO-230/231 与伴随报警。
2. 对照本机电气原理图确定失配的双通道信号，再检查现场安全设备与连接回路。诊断范围可包括安全门锁、外部急停、伺服关闭输入、安全 PLC/继电器、端子和线缆，但不能脱离安全设计图纸盲目测线或改线。
3. 修复后先做安全功能测试。若故障来自围栏双通道，应验证开门时两路均产生预期安全动作，关门后才具备恢复条件；其他安全信号同理。

**Chain Error Reset 边界：**

1. 仅当故障原因已定位并修复后，才能执行专用复位。R-30iB 手册给出两种入口：`SYSTEM > SYSTEM SETTING > Chain Error Reset Execution`，或 `ALARM` 页面中的 `CHAIN RESET` 功能键；实际菜单受软件版本和权限影响。
2. 专用复位完成后，再按现场程序执行普通报警复位与受控启动。
3. 若专用复位后报警再次出现，应停止复机，继续查找未消除的单通道故障或时序异常；不得反复复位以“观察是否恢复”。

**严禁做法：**

- 不得在故障尚未识别和修复时执行 Chain Error Reset。
- 不得以跳线、短接、强制 I/O 或屏蔽报警来让双通道安全链“看起来一致”。
- 不得把同一修复方法套用于不同柜型、不同软件版本或不同安全架构。

### 5. 预防措施

1. 定期对外部急停、安全门/围栏、伺服关闭和使能设备进行双通道功能测试，并保存两路动作结果。
2. 对安全 PLC、继电器和门锁改造实行图纸版本控制、风险评估、验证测试与复机审批。
3. 对有振动、频繁开关门或潮湿污染的现场，重点检查端子紧固、线缆磨损和连接器锁紧状态。
4. 培训维护人员区分“普通报警复位”和“安全链错误专用复位”，并要求在报警历史中记录伴随代码和根因。
