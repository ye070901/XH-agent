## 正文

### 1. 模板匹配原理

模板匹配是在大图中滑动模板图像，逐位置计算模板与对应区域的相似度，得到一张匹配响应图，再取最亮点（或最暗点）作为最佳位置。OpenCV 的 `cv2.matchTemplate()` 实现多种比较方法：

- `cv2.TM_SQDIFF`：平方差，越小越匹配，需取 `minMaxLoc` 最小值；
- `cv2.TM_CCOEFF_NORMED`：归一化相关系数，越大越匹配，工业中最常用。

响应图尺寸为 (W−w+1, H−h+1)，其中 W×H 为输入图、w×h 为模板。

### 2. 基本用法（OpenCV/Python）

```python
import cv2

img = cv2.imread('scene.png', 0)      # 待搜索场景图
tpl = cv2.imread('template.png', 0)   # 模板
w, h = tpl.shape[::-1]

res = cv2.matchTemplate(img, tpl, cv2.TM_CCOEFF_NORMED)
min_val, max_val, min_loc, max_loc = cv2.minMaxLoc(res)
# 最佳匹配左上角
top_left = max_loc
bottom_right = (top_left[0] + w, top_left[1] + h)
cv2.rectangle(img, top_left, bottom_right, 255, 2)
print("得分:", max_val, "位置:", max_loc)
```

匹配前通常先做灰度化、直方图均衡或去噪；对明暗变化敏感时可用归一化方法并在模板制作时保证光照一致。

### 3. 工程适用边界

| 场景 | 模板匹配适用性 | 说明 |
|------|----------------|------|
| 位置平移搜索 | 适用 | 目标是模板的平移副本即可 |
| 有平面旋转 | 受限 | 需生成多角度模板或改用形状匹配 |
| 有尺度变化 | 受限 | 需多尺度模板或形状匹配 |
| 高反光、光照剧烈变化 | 谨慎 | 对灰度敏感的相关系数法会失效 |
| 遮挡部分目标 | 差 | 模板匹配对遮挡鲁棒性弱 |

### 4. 与形状匹配的对比

工业视觉平台（如 HALCON 等）提供的基于形状/轮廓的匹配（Shape-Based Matching），通过几何边缘梯度进行匹配，对光照变化、一定程度的遮挡、旋转与缩放更鲁棒，能输出亚像素级的平移与角度。灰度模板匹配实现简单、适合规则且光照稳定的场景；复杂工件的鲁棒定位应优先考虑形状匹配方案。

### 5. 验证方法与常见问题

| 问题 | 对策 |
|------|------|
| 误匹配出现在错误位置 | 提高匹配阈值，检查模板是否含背景 |
| 位置抖动 | 亚像素细化（对响应图插值求极值） |
| 光照变化失效 | 改用归一化方法或形状匹配 |
| 需要角度/缩放 | 建立多角度多尺度模板库 |

验收：使用与生产相同光照下的样板图测试，正确率与重复精度均达标后，再接入相机标定与手眼标定输出机器人坐标。
