## 正文

### 1. Eye-in-Hand 配置特点

相机安装在机器人法兰/末端，优点是相机跟随工具运动、可近距离观测目标、不受固定视场限制；缺点是成像时相机位姿随机器人变化，标定需考虑末端运动，且大负载/高速时会引入随动定位误差。

### 2. 标定目标

Eye-in-Hand 要求解相机坐标系与机器人末端（工具/法兰）坐标系之间的固定齐次变换 $T_{cam}^{tool}$。该变换在机器人运动过程中保持不变，一旦求得，即可将相机观测到的目标坐标转换到末端坐标，再经机器人运动学与正解转到基座坐标系执行。

### 3. 标定流程

1. **相机安装与内参标定**：固定相机于末端（注意工具坐标系/负载载荷设置），单独完成相机内参标定；
2. **准备标定板**：将标定板固定在工作空间内稳定位置（不随机器人运动）；
3. **采集多组位姿**：控制机器人以不同位姿（尤其保证姿态变化差异大）对同一标定板成像，记录每组：(a) 机器人末端位姿（正解读出），(b) 标定板在相机坐标系中的位姿（标定板角点解算）；
4. **求解 AX=XB**：用 `calibrateHandEye`（OpenCV）等求解 $T_{cam}^{tool}$；
5. **验证**：用未参与求解的位姿把相机观测的目标点转换到机器人坐标，对比机器人实测位姿的误差。

### 4. 采集策略与精度要点

| 策略 | 说明 |
|------|------|
| 位姿差异化 | 旋转方向差异尽量大，避免共线/共面退化 |
| 样本数量 | 通常 10~15 组以上 |
| 标定板覆盖 | 标定板在视场内不同位置与倾角成像 |
| 先内参后手眼 | 内参误差会传导到手眼结果 |
| 机器人精度 | 末端绝对位姿精度影响标定精度，必要时做机器人校准 |

### 5. 验证与常见问题

| 现象 | 原因与对策 |
|------|------------|
| 验证误差大 | 位姿变化样本不足，增加差异化采集 |
| 运动后定位漂移 | 末端载荷/变形、线缆拉扯，检查安装 |
| 相机内参不准影响大 | 重新做内参标定 |
| 退化配置 | 避免所有采集点标定板只在一个小角度范围内 |

验收：定点验证偏差满足工艺公差；机器人以大范围姿态运动后视觉引导仍稳定。
