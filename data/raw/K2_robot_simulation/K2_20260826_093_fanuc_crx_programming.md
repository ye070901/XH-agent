## 正文

CRX 系列延续 FANUC TP（示教器）编程体系，同时新增协作特性：拖动示教、安全碰撞检测、功率力限制，人机可直接协作。

### 一、示教器基本操作

1. 切换运行模式：手动（T1/T2）与自动。
2. 坐标系切换：关节/世界/工具/用户坐标系。
3. 用点动键移动机器人，记录示教点。

### 二、拖动示教记录点位

1. 进入拖动示教模式，握持机械臂末端。
2. 手动拖到目标位，松开后按"记录"保存为位置点。
3. 重复记录取料、放料等关键点。

### 三、TP 程序结构

```tp
   1:  J PR[1] 100% FINE       ; 移动到取料点
   2:  RO[1]=ON                ; 夹爪闭合
   3:  L PR[2] 500mm/s CNT50   ; 搬运到放料点
   4:  RO[1]=OFF               ; 夹爪打开
   5:  J PR[3] 100% FINE       ; 返回
```

### 四、协作参数配置

| 参数 | 说明 |
|------|------|
| 碰撞检测灵敏度 | 按负载调整 |
| 功率力限制 | 限制关节力矩 |
| 安全停止 | 人接近时停止 |
| 速度倍率 | 协作模式限速 |
