## 正文

拖动示教利用关节力矩传感器感知操作员施加的外力，控制器将外力转化为运动，让机械臂"跟着手走"。松开后位置被记录为示教点，适用于搬运、装配等轨迹不规则的应用。

### 一、启用拖动示教

1. 选择"手把手引导"模式（通常在示教器或手持使能器上切换）。
2. 握持使能键，沿期望轨迹移动机器人。
3. 到位后按记录键保存当前点。

### 二、点位记录与轨迹

```text
拖动示教记录流程（以装配为例）
1. 空载拖动到取料点 → 记录 P1
2. 拖动到预装配点 → 记录 P2
3. 拖动到装配位 → 记录 P3
4. 回放：P1 → P2 → P3，设置过渡速度
```

### 三、调试要点

| 项目 | 建议 |
|------|------|
| 拖动速度 | 先慢后快，防止过冲 |
| 负载识别 | 记录点前先确认负载参数正确 |
| 姿态保持 | 拖动末端时保持工具姿态稳定 |
| 点位微调 | 拖动后可用坐标偏移微调 |

### 四、常见问题

- **松手后漂移**：力矩传感器零点偏移，执行重力补偿/零点标定。
- **点位不准**：拖动过快或负载未识别，重拖并降低速度。
- **误记录**：确认使能键状态，记录前停稳。
