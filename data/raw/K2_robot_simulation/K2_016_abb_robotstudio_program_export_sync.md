## 正文

离线编程完成后，最关键的一步是把虚拟工作站里的 RAPID 程序搬到真实机器人上。核心思路：先在 RobotStudio 中用**虚拟控制器（Virtual Controller）**完整运行一遍程序，确认逻辑与运动无误后，再通过备份（Backup）或在线同步把程序下发到真机。

### 一、在虚拟控制器中验证程序

1. 工作站创建时选择「带虚拟控制器」，并勾选与现场一致的 RobotWare 版本与工艺选项（如焊接、码垛对应选项）。
2. 用 `RAPID → Test and Debug → Start` 或示教器面板上的「启动」单步/连续运行程序，观察仿真中的运动轨迹、信号交互与节拍。
3. 重点检查：工具数据 `tool`、工件坐标 `wobj` 是否与真实工装一致；IO 信号名称是否对齐。

```rapid
! 程序首启安全模板
MODULE MainModule
    PROC main()
        ! 上电自检：确认零点与工具数据
        IF NOT CalibCheck() THEN
            TPWrite "零点异常，请校准";
            RETURN;
        ENDIF
        MoveAbsJ [[0,0,0,0,0,0],[9E9,9E9,9E9,9E9,9E9,9E9]]\NoEOffs, v200, fine, tool0;
        ! 进入作业循环
        ProductionLoop;
    ENDPROC
ENDMODULE
```

### 二、导出与真机同步的两种方式

**方式 A：备份还原（推荐，适合整站迁移）**

1. 虚拟控制器上执行 `File → Save System As` 或在示教器面板 `Backup`，生成一个备份文件夹（含 `HOME`、`RAPID`、`SYS`、`EIO` 等）。
2. 将该备份拷贝到 U 盘，插入真实控制器，用示教器 `Restore` 恢复到真机。
3. 注意：备份会覆盖真机系统参数（包括 IO 配置、坐标系），只应在**新机首次上电或授权允许时**使用。

**方式 B：在线连接 / 程序级同步（适合增量修改）**

1. RobotStudio 切换到「Online」模式，输入真实控制器 IP（如 `192.168.1.10`）。
2. 通过 `RAPID` 视图右键「Synchronize to Station / Load Program」，把已改程序模块下发到控制器。
3. 也可用 FTP 把 `.mod`、`.sys` 文件传到控制器内存，再在示教器上加载。

### 三、真机首启安全检查清单

| 序号 | 检查项 | 说明 |
|------|--------|------|
| 1 | 急停回路 | 手动拍急停可正常停止，状态灯变化 |
| 2 | 速度倍率 | 首次运行置于 ≤25%，确认轨迹安全后逐步提升 |
| 3 | 单步执行 | 先用 `Step` 逐行验证，再连续运行 |
| 4 | 坐标系确认 | 手动模式下逐个核对 `wobj`、`tool` 与实际工装 |
| 5 | 程序指针 | 从 `main` 入口运行，避免从中间启动 |
