## 正文

KUKA ArcTech 将复杂的弧焊过程标准化，工程师无需直接操控焊机，而是通过**焊接数据集（Weld Data, WDAT）**与标准焊接指令完成编程。同一套 KRL 程序在 KUKA.Sim 离线仿真与真机中可复用。

### 一、焊接指令集

| 指令 | 作用 |
|------|------|
| `ARCON WDAT1` | 起弧：打开焊机、按数据集参数起弧 |
| `ARC_SE1` / `ARC_SE2` | 焊缝起点/终点定义（含摆动与焊缝跟踪） |
| `ARCOFF` | 收弧：按收弧参数熄弧 |
| `ARC_SWI` | 切换焊接数据集 |

### 二、焊接数据集（WDAT）关键参数

在 WorkVisual/KUKA.Sim 的 ArcTech 配置中，每个 WDAT 包含：

- **焊接工艺参数**：焊接电压、电流、送丝速度、气体流量。
- **起弧/收弧参数**：回烧时间、填弧坑参数。
- **摆动参数**：摆动类型（正弦/三角）、摆动宽度、频率。
- **焊缝跟踪**：是否启用激光/电弧跟踪及其传感器参数。

### 三、典型焊缝程序

```krl
DEF welddemo( )
  BAS(#INITMOV, 0)
  $BASE = {X 600, Y 0, Z 700, A 0, B 0, C 0}
  $TOOL = {X 0, Y 0, Z 250, A 0, B 0, C 0}

  PTP {A1 0, A2 -90, A3 90, A4 0, A5 90, A6 0}   ; 焊前安全位
  LIN {X 650, Y 0, Z 500, A 0, B 90, C 0}        ; 接近焊缝起点

  ARCON WDAT1                                     ; 起弧
  ARC_SE1 {X 650, Y 0, Z 450, A 0, B 90, C 0}     ; 焊缝起点
  ARC_SE2 {X 850, Y 0, Z 450, A 0, B 90, C 0}     ; 焊缝终点（直线焊接）
  ARCOFF                                          ; 收弧

  LIN {X 850, Y 0, Z 500, A 0, B 90, C 0}         ; 离开焊缝
  PTP {A1 0, A2 -90, A3 90, A4 0, A5 90, A6 0}    ; 回安全位
END
```

### 四、多层多道焊策略

多层多道焊通过**焊缝偏移**实现：对同一条焊缝，用偏移参数（横向偏移 `WELD_OFFSET` 或自定义 BASE 平移）逐道焊接，每道调整 WDAT 参数（电流/摆动宽度）。

### 五、离线仿真要点

- 在 KUKA.Sim 中启用 ArcTech 选件，导入焊枪工具并标定 TCP（焊丝尖端）。
- 用**碰撞检测**检查焊枪与工件的接近姿态，避免焊嘴碰撞。
- 焊缝跟踪传感器在纯离线仿真中一般用理想轨迹代替，真机再启用跟踪。

### 六、常见问题

| 现象 | 原因 | 对策 |
|------|------|------|
| 起弧失败 | WDAT 参数/焊机通讯未配 | 检查 ArcTech 工艺包与焊机接口 |
| 焊缝偏移 | BASE/TOOL 未标定 | 重新标定 TCP 与工件基坐标 |
| 收弧不良 | 回烧/填弧坑参数不当 | 调整 WDAT 收弧参数 |
