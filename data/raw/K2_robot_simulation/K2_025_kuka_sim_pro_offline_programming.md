## 正文

KUKA.Sim Pro（4.0 起）是面向 KUKA 机器人的专业离线编程平台，内置 KRL 编辑器（含语法高亮与代码补全），支持原生 KRL 执行、碰撞检测、运动监控与节拍估算，并可通过 KUKA.Connectivity 与真实控制器通讯，实现"离线编好、真机直接用"。

### 一、工作站搭建

1. 新建项目，从 KUKA 机器人库导入对应型号（如 KR 210 R2700）。
2. 导入工件与工装的 CAD 几何（STEP/IGES）。
3. 设置**底座坐标系（ROBROOT）**与**工具坐标系（TOOL）**、**基坐标系（BASE）**，保证与真实工位一致。
4. 为机器人配置控制器（KRC4/KRC5）及所需工艺选项（如 ArcTech）。

### 二、KRL 程序离线编写

```krl
&ACCESS RVP
DEF main( )
  ; 初始化
  BAS(#INITMOV, 0)
  $BASE = {X 500, Y 0, Z 800, A 0, B 0, C 0}
  $TOOL = {X 0, Y 0, Z 200, A 0, B 0, C 0}

  ; 关节运动到安全点
  PTP {A1 0, A2 -90, A3 90, A4 0, A5 0, A6 0}
  ; 直线运动到目标点
  LIN {X 600, Y 100, Z 500, A 0, B 90, C 0}
  ; 结束
END
```

### 三、仿真验证与节拍估算

1. 在 KRL 编辑器中编译（Check）程序，确保无语法错误。
2. 运行仿真，观察运动轨迹、检查**碰撞检测**与**奇异点**。
3. 使用节拍估算（Cycle Time）功能评估单循环时间，优化路径与速度。

### 四、模块传输到真机

1. 通过 KUKA.Connectivity 用网线连接真实 KRC 控制器（IP 需在同一网段）。
2. 把仿真中验证通过的 `.src`/`.dat` 模块上传到控制器。
3. 在示教器（KSS）中加载程序，先 T1 低速单步验证，再转 AUT 自动运行。

### 五、KUKA.Sim 的边界（需注意）

- 复杂程序（含 EKI、RSI、力控等选件）在 KUKA.Sim 中支持有限，需在 KUKA OfficeLite 或真机验证。
- 离线标定的坐标系与真机存在偏差时，需现场重新标定 BASE/TOOL。

### 六、常见问题

| 现象 | 原因 | 对策 |
|------|------|------|
| 模块上传失败 | IP/网段不一致 | 检查 KUKA.Connectivity 网络配置 |
| 仿真轨迹与真机不符 | BASE/TOOL 未对齐 | 现场重新标定 |
| 节拍偏慢 | 路径冗余/速度未优化 | 优化 PTP/LIN 组合 |
