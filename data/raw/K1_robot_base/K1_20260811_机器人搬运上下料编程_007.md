## 正文

### 1. 典型搬运流程

```
1. 初始位置 (Home Point)
       ↓
2. 移动到取料位置上方
       ↓
3. 下降到位 → 执行抓取
       ↓
4. 上升 → 移动到放料位置上方
       ↓
5. 下降到位 → 执行放置
       ↓
6. 返回初始位置
```

### 2. FANUC 搬运编程要点

| 步骤 | 关键设置 |
|------|----------|
| 取料点示教 | 设置接近点、抓取点、释放点 |
| 放料点示教 | 使用用户坐标系，便于位置调整 |
| 轨迹规划 | 避免奇异点和碰撞 |
| 速度设置 | 取放料时使用较低速度 |
| 信号交互 | 设置夹具的开关信号 |

### 3. ABB 搬运编程要点

| 步骤 | 关键设置 |
|------|----------|
| 取料点示教 | 设置安全上方点 Offs(pPick,0,0,100) |
| 放料点示教 | 使用工件坐标系 wobjdata |
| 轨迹规划 | 安全移动用 MoveJ，精确路径用 MoveL |
| 速度设置 | 取放料时使用 v300 以下速度 |
| 信号交互 | SetDO/Reset 控制夹爪，WaitTime 等待 |

### 4. FANUC 搬运程序完整示例

```tp
程序名: PICK_PLACE
==================================

1:  J P[2] 100% FINE       // 移动至取料上方安全点
2:  L P[1] 500mm/s FINE    // 直线下降至取料点
3:  RO[1]=ON               // 夹爪闭合
4:  WAIT 0.50(sec)         // 等待夹爪闭合
5:  L P[2] 500mm/s FINE    // 直线提升至安全高度
6:  J P[3] 100% FINE       // 关节移动至放料上方安全点
7:  L P[4] 500mm/s FINE    // 直线下降至放料点
8:  RO[1]=OFF              // 夹爪松开
9:  WAIT 0.50(sec)         // 等待夹爪松开
10: L P[3] 500mm/s FINE   // 直线提升至安全高度
11: J P[5] 100% FINE      // 返回原点位置
```

### 5. ABB RAPID 搬运程序完整示例

```rapid
MODULE K1_PICK_PLACE
    CONST robtarget pHome:=[[0,0,800],[1,0,0,0],[-1,0,0,0],0];
    CONST robtarget pPick:=[[300,200,150],[0,0,1,0],[-1,0,0,0],0];
    CONST robtarget pPickSafe:=[[300,200,250],[0,0,1,0],[-1,0,0,0],0];
    CONST robtarget pPlace:=[[300,-200,150],[0,0,1,0],[-1,0,0,0],0];
    CONST robtarget pPlaceSafe:=[[300,-200,250],[0,0,1,0],[-1,0,0,0],0];
    PROC main()
        ! 回到原点
        MoveJ pHome,v1000,z100,tool0;
        ! 移动到取料安全上方点
        MoveJ pPickSafe,v800,z50,tool0;
        ! 直线下降到取料点
        MoveL pPick,v300,fine,tool0;
        ! 夹爪闭合
        SetDO do_grip,1;
        WaitTime 0.2;
        ! 直线上升到取料安全上方点
        MoveL pPickSafe,v300,z50,tool0;
        ! 移动到放料安全上方点
        MoveJ pPlaceSafe,v800,z50,tool0;
        ! 直线下降到放料点
        MoveL pPlace,v300,fine,tool0;
        ! 夹爪松开
        Reset do_grip;
        WaitTime 0.2;
        ! 直线上升到放料安全上方点
        MoveL pPlaceSafe,v300,z50,tool0;
        ! 返回原点
        MoveJ pHome,v1000,z100,tool0;
    ENDPROC
ENDMODULE
```

### 6. 点位规划说明

| 点位 | 说明 | 指令选择 |
|------|------|----------|
| pHome | 原点安全位置 | MoveJ (快速) |
| pPickSafe | 取料安全上方点 | MoveJ (快速) |
| pPick | 取料精确点 | MoveL (精确) |
| pPlaceSafe | 放料安全上方点 | MoveJ (快速) |
| pPlace | 放料精确点 | MoveL (精确) |

### 7. 安全高度设置

安全高度通常设置为：
- 取料点上方 100mm
- 放料点上方 100mm

使用 Offs 函数计算安全点：
```rapid
pPickSafe := Offs(pPick, 0, 0, 100);  // Z轴方向偏移100mm
```

### 8. IO 信号控制

| 操作 | FANUC 指令 | ABB 指令 |
|------|-----------|----------|
| 夹爪闭合 | RO[1]=ON | SetDO do_grip,1 |
| 夹爪松开 | RO[1]=OFF | Reset do_grip |
| 等待时间 | WAIT 0.50(sec) | WaitTime 0.5 |

### 9. 速度设置建议

| 运动类型 | FANUC 速度 | ABB 速度 | 说明 |
|----------|-----------|----------|------|
| 安全点移动 | 100% | v800~v1000 | 快速移动 |
| 接近/离开工件 | 500mm/s | v500~v800 | 中等速度 |
| 取放料精确点 | 500mm/s | v200~v300 | 低速精确 |

### 10. 编程注意事项

| 注意事项 | 说明 |
|----------|------|
| 取料前确认 | 物料位置正确，夹爪可顺利抓取 |
| 放料空间 | 放料位置应留有足够空间 |
| 轨迹平滑 | 避免急转，减少振动和碰撞风险 |
| 负载参数 | 根据物料重量设置合适的负载参数 |
| 奇异点 | 避开奇异点位置，必要时增加过渡点 |

### 11. 工件坐标系的优势

使用工件坐标系的优势：
- 工作台重新移位后，只需更改工件坐标系数据
- 所有路径自动更新
- 无需重新逐个示教点位
- **提高编程效率，节省时间成本**
