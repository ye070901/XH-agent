## 正文

### 1. 点云是什么

点云是三维空间点的集合，每个点通常包含 x、y、z 坐标，可附带法向、颜色、强度等属性。工业 3D 视觉（激光三角/结构光/ToF/双目）输出的深度图可反投影为点云。点云是 3D 视觉处理（滤波、配准、分割、识别、定位）的基础数据。

### 2. 点云噪声来源

- 高反光/黑亮表面造成深度缺失或飞点；
- 环境光干扰、边缘遮挡；
- 传感器自身的测量噪声；
- 运动模糊（动态采集时）。

预处理的目的就是降低噪声、控制数据量、提取有效区域。

### 3. 常见预处理操作（PCL）

| 操作 | 作用 | 典型实现 |
|------|------|----------|
| 体素降采样 | 用体素内点云质心近似整体，大幅减少点数并平滑表面 | `pcl::VoxelGrid` |
| 直通滤波 | 裁剪 ROI 范围（x/y/z 区间） | `pcl::PassThrough` |
| 统计离群点剔除 | 剔除明显偏离邻域统计分布的孤立点 | `StatisticalOutlierRemoval` |
| 半径离群点剔除 | 邻域点数过少即判为噪声 | `RadiusOutlierRemoval` |
| 表面法向估计 | 计算每个点的法向量，供分割与配准使用 | `NormalEstimation` |

VoxelGrid 示例思想：

```cpp
pcl::VoxelGrid<pcl::PointCloud<pcl::PointXYZ>> sor;
sor.setInputCloud(cloud);
sor.setLeafSize(0.01f, 0.01f, 0.01f);   // 体素边长 1cm
sor.filter(*cloud_filtered);
```

### 4. 预处理流水线建议

```
原始点云 → 直通滤波(取 ROI) → 统计离群点剔除(去飞点)
   → VoxelGrid 降采样(控点数) → 法向估计 → 后续(配准/分割/识别)
```

先裁剪 ROI 能显著减少后期计算量；降采样的体素尺寸需与测量精度需求平衡——体素过大丢失细节、过小降不下来。

### 5. 验证与常见问题

| 现象 | 对策 |
|------|------|
| 点数过多导致处理慢 | 加大 VoxelGrid 体素或收紧 ROI |
| 飞点/离群点干扰识别 | 调离群点剔除参数 |
| 细节被平滑掉 | 减小体素尺寸 |
| 高反光表面空洞 | 改善环境光控制或多次采集融合 |

验收：处理后点云在目标特征上保持可识别且点数/耗时满足节拍；后续配准或识别结果稳定。
