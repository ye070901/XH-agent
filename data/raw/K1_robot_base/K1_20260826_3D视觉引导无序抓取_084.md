## 正文

### 1. 无序抓取的应用意义

料筐/料箱内工件随机堆放时，传统 2D 视觉无法判断工件深度与姿态。3D 视觉通过点云直接获得每个工件的三维位置与姿态，使机器人能逐个从杂乱堆料中稳定抓取，从而省去人工排料，提升自动化柔性。

### 2. 无序抓取系统链路

```
3D相机采集 → 点云预处理(ROI/滤波/降采样) → 目标分割与识别
   → 计算抓取位姿(位置+姿态) → 接近方向与夹爪避碰检查
   → 机器人执行抓取 → 失败检测与重试
```

3D 相机可装在机器人末端（眼在手上）或固定在料筐上方（眼在手外）。固定相机覆盖整个料筐、节拍更快；末端相机视野近、随动灵活但需处理随动运动学。

### 3. 定位与抓取规划要点

| 环节 | 要点 |
|------|------|
| 目标分割 | 用平面分割去除料筐底面/壁面，再聚类分离工件 |
| 姿态求解 | 对每个工件拟合模型/轮廓计算 6DoF 位姿 |
| 可抓取性判断 | 依据接近方向是否被相邻件遮挡、夹爪空间是否干涉 |
| 抓取顺序 | 优先抓取最高、最外、姿态最明确的工件 |
| 吸盘/夹爪适配 | 吸盘对平整面友好，夹爪需评估干涉 |

### 4. 失败与防碰撞策略

- 抓取前计算无碰撞接近/抬离路径，可用离线仿真校验（如 ABB RobotStudio/RobotStudio 带视觉扩展）；
- 抓取失败（无真空确认/夹取落空）立即复位并尝试下一个目标；
- 料筐底部漏抓完成后切换新料筐；
- 关键路径上保留慢速调试模式与人工干预入口。

### 5. 验证与常见问题

| 现象 | 原因与对策 |
|------|------------|
| 抓取点偏移 | 手眼标定/相机标定误差，重标定 |
| 姿态判断错误 | 分割不干净，优化 ROI 与平面分割 |
| 夹爪碰到相邻件 | 增加干涉检查与接近方向约束 |
| 高反光件漏检 | 调整光源/相机角度，或多次采集 |

验收：对典型混装料筐统计单筐抓取成功率与空抓率，达到工艺目标（常要求较高的首抓成功率）且无碰撞事故；相机位姿、料筐位置变化后重新标定。
