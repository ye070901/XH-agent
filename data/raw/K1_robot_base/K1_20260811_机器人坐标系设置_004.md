## 正文

### 1. ABB 四大坐标系

| 坐标系 | 说明 | 特性 |
|--------|------|------|
| **大地坐标系 (World Frame)** | 绝对参考基准 | 唯一、不可修改、全局基准 |
| **基坐标系 (Base Frame)** | 机器人底座中心为原点 | 与安装方式直接相关 |
| **工具坐标系 (Tool Frame)** | 以工具末端为原点 | 描述TCP位置和姿态 |
| **工件坐标系 (User Frame)** | 用户自定义工作平面 | 便于程序移植 |

### 2. 大地坐标系特点

ABB机器人的大地坐标系具有以下关键特性：
- **唯一性**：一个工作站有且只有一个大地坐标系
- **不可修改**：在ABB系统中默认固定，用户无法直接更改
- **全局基准**：所有其他坐标系最终都映射到大地坐标系

在RobotStudio仿真软件中，大地坐标用灰色坐标系图标表示，通常与第一台机器人的基坐标重合。

### 3. 工具数据 (tooldata) 设置

#### 3.1 基本概念

**定义**：描述工具（夹爪、吸盘等）的尺寸、重量和姿态

**参数说明**：
| 参数 | 说明 |
|------|------|
| `trans.x/y/z` | TCP位置，从法兰盘中心到末端的距离(mm) |
| `mass` | 工具质量(kg) |
| `robhold` | TRUE = 机器人持有工具 |
| `cog` | 载荷重心位置 |

#### 3.2 设置步骤

```
主菜单 → 程序数据 → tooldata → 新建 → 定义
```

#### 3.3 标定方法

| 方法 | 说明 |
|------|------|
| **四点法** | X方向点1-2, Y方向点1-3, 原点 |
| **六点法** | 更精确的姿态标定 |
| **直接输入偏移量** | 直接输入已知的TCP偏移值 |

#### 3.4 工具数据示例

```
PERS tooldata tGrip:= [TRUE, [...], [...], [1, 0, 0, 0], [0, 0, 215.3]];
! trans.z = 215.3 表示从法兰盘中心到工具末端(TCP)的距离是215.3毫米
! mass = 1 表示工具质量1公斤
```

### 4. 工件数据 (wobjdata) 设置

#### 4.1 基本概念

**定义**：描述工作台或工件的坐标系

**作用**：
- 以工件为基准来描述TCP运动
- 工作台重新移位后，只需更改工件坐标系数据，所有路径自动更新
- **提高编程效率，节省时间成本**

#### 4.2 设置步骤

```
ABB菜单 → 程序数据 → wobjdata → 新建 → 编辑 → 定义
```

#### 4.3 3点示教法标定步骤

1. **用户点X1 (原点)**：示教工件原点位置
2. **用户点X2 (X方向)**：沿X轴正方向移动到参考点（距离尽可能远）
3. **用户点Y1 (Y方向)**：沿Y轴正方向移动到参考点

**重要注意**：移动过程中不能旋转C轴，否则计算结果会出错

### 5. ABB坐标系选择

ABB机器人可选坐标系（线性/重定位模式下）：
| 坐标系 | 说明 |
|--------|------|
| 大地坐标系 | 机器人安装的基础坐标系 |
| 基座坐标系 | 机器人底座中心为原点 |
| 工件坐标系 | 用户自定义的工作平面 |
| 工具坐标系 | 以工具末端为原点 |

### 6. 工件坐标系的优势

使用工件坐标系的好处：
- 工作台移位后，只需更改工件坐标系数据
- 所有路径自动更新
- 无需重新逐个示教点位
- 便于程序移植到其他工作站

### 7. 不同安装场景的定位规则

根据机器人安装方式的不同：
- 大地坐标与基坐标的重合关系会因配置方式而变化
- 实际物理系统中需要根据现场情况确定坐标系关系

### 8. 常见问题与解决

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| MoveL目标位置不可达 | 7轴手臂角度奇异点、双臂干涉、工具TCP未标定 | 切换手臂运动模式调整姿态，增大Collision Avoidance安全距离，重新标定工具坐标系 |
| 导通拖拽模式手臂僵硬 | 负载参数设置错误、摩擦补偿系数过低 | 修正有效负载，调高系统参数Friction comp. lead through factor至0.6~0.8 |
| 开机后微动无法定位 | 电池亏电导致转数计数器数据丢失 | 对齐各轴校准标记，运行CalHall子程序更新转数计数器 |
