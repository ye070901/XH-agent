## 正文

### 1. KUKA 坐标系类型

KUKA 机器人编程主要使用以下几种坐标系：

| 坐标系类型 | 说明 | 用途 |
|-----------|------|------|
| **基坐标系 (Base)** | 机器人参考坐标系 | 位于机器人基座或工作空间固定点 |
| **工具坐标系 (Tool)** | 末端执行器的坐标系 | 定义TCP位置和姿态 |
| **工件坐标系 (Workpiece)** | 工件参考系 | 相对于基坐标系的工件参考点 |

### 2. 工具坐标系标定方法

#### 2.1 XYZ 4点法

**适用范围**：主要用于焊枪和加工类抓手刀具

**操作步骤**：
```
投入运行 → 测量 → 工具 → XYZ 4点
```

1. 为工具指定编号和名称
2. 用TCP移至任意参照点，按"测量"确认
3. 从3个不同方向重复移向参照点
4. 输入负载数据
5. 保存TCP数据（X、Y、Z值）

**精度要求**：误差一般允许0.5mm

#### 2.2 ABC 两点法

**适用范围**：主要用于开合的夹爪类工具

**特点**：只需2个点即可完成标定

#### 2.3 XYZ 参照法

**适用范围**：已知上一个工具坐标系参数，计算新工具坐标系

**应用场景**：工具快换后快速恢复坐标系

#### 2.4 ABC 世界坐标法

| 模式 | 说明 |
|------|------|
| **5D** | 确定X轴方向 |
| **6D** | 确定全部三轴方向 |

### 3. 基坐标系标定方法

#### 3.1 3点法

**操作步骤**：
1. 原点：示教基坐标系原点位置
2. X正方向点：沿X轴正方向示教一点
3. XY投影方向点：确定XY平面

#### 3.2 间接法

**适用场景**：机器人无法到达原点时

**方法**：延伸出基于原点的4个位置来间接确定坐标系

#### 3.3 直接输入法

**适用场景**：已知仿真数据

**方法**：直接输入坐标值

### 4. 基坐标系标定步骤

```
投入运行 → 测量 → 基坐标 → 3点法
```

1. 进入基坐标系标定界面
2. 选择要设置的基坐标系编号
3. 示教原点位置
4. 示教X正方向点
5. 示教XY投影方向点
6. 保存基坐标数据

### 5. 操作注意事项

| 注意事项 | 说明 |
|----------|------|
| 先工具后基座 | 建立基座标前必须先建立工具坐标 |
| 版本差异 | 新版本(8.6及以上)与旧版本(8.3)菜单位置有所不同 |
| T1档运行注意 | 在T1档运行时注意观察工具是否压到工件 |
| 标定精度 | TCP标定误差一般允许0.5mm |

### 6. 坐标系数据查看

标定完成后，可在以下位置查看坐标系数据：
- 投入运行 → 测量 → 工具/基坐标 → 查看详细数据

### 7. 坐标系设置流程图

```
开始
    ↓
创建工具数据
    ↓
标定工具坐标系 (XYZ 4点法)
    ↓
输入负载数据
    ↓
保存工具数据
    ↓
创建基坐标数据
    ↓
标定基坐标系 (3点法)
    ↓
保存基坐标数据
    ↓
完成
```
