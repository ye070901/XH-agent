## 正文

### 1. 坐标系的重要性

工业机器人的所有运动都需要在特定坐标系下进行描述。理解并正确设置坐标系是安全、高效操作机器人的基础。ISO 10218-1:2025标准第5.3节明确规定了工业机器人必须具备的坐标系配置能力。

### 2. 坐标系类型对比

| 坐标系类型 | FANUC | KUKA | ABB | 说明 |
|-----------|-------|------|-----|------|
| **基坐标系** | BASE | Base | Base Frame | 机器人安装基础坐标系 |
| **工具坐标系** | UTOOL | Tool | Tool Frame (tooldata) | 末端执行器参考系 |
| **用户坐标系** | UFRAME | Workpiece | User Frame (wobjdata) | 工件参考系 |
| **大地坐标系** | WORLD | World | World Frame | 全局绝对参考 |

### 3. 坐标系层次关系

```
坐标系层次结构
==================================

1. 大地坐标系 (World)
   - 定义：机器人安装的基础全局参考坐标系
   - 特性：具有唯一性，不可修改

2. 基坐标系 (Base/基座)
   - 挂载于大地坐标系之下
   - 定义：机器人底座中心为原点
   - 用途：描述机器人本身的位置和姿态

3. 用户坐标系 (User Frame/工件坐标)
   - 挂载于基坐标系之下
   - 定义：用户自定义的工作平面坐标系
   - 作用：以工件为基准来描述TCP运动

4. 工具坐标系 (Tool/TCP)
   - 挂载于用户坐标系之下
   - 定义：以工具末端（TCP）为原点的坐标系
   - 作用：描述工具位置和姿态，使示教编程更加灵活

5. 工具末端工作点 (TCP Point)
   - 挂载于工具坐标系之下
   - 定义：TCP在用户坐标系中的实际位置
```

> **标准参考**: ISO 10218-1:2025 规定了工业机器人必须具备的坐标系配置能力，确保操作安全性和编程灵活性。

### 4. 各坐标系简介

1 大地坐标系 (World)

- **定义**：机器人安装的基础全局参考坐标系
- **特性**：
  - 具有唯一性，一个工作站有且只有一个
  - 不可修改，用户无法直接更改
  - 所有其他坐标系最终都映射到大地坐标系

2 基坐标系 (Base)

- **定义**：机器人底座中心为原点的坐标系
- **特性**：与机器人安装方式直接相关
- **用途**：描述机器人本身的位置和姿态

3 工具坐标系 (Tool/UTOOL)

- **定义**：以工具末端（TCP）为原点的坐标系
- **作用**：描述工具位置和姿态，使示教编程更加灵活
- **默认值**：原点位于J6轴法兰中心

4 用户坐标系 (User/UFRAME)

- **定义**：用户自定义的工作平面坐标系
- **作用**：以工件为基准来描述TCP运动
- **优势**：工作台移位后只需更改坐标系数据，所有路径自

5 标系选择原则

| 场景 | 推荐坐标系 | 原因 |
|------|-----------|------|
| 描述机器人整体位置 | 大地坐标系/基坐标系 | 全局参考 |
| 工具定位 | 工具坐标系 | 以TCP为参考 |
| 工件相关运动 | 用户坐标系 | 便于编程和调整 |
| 精确路径控制 | 根据具体需求选择 | 确保路径准确性 |
