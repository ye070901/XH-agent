# 机器人操作初学者常见误区-操作指南

- **来源**：ABB IRC5 机器人紧急安全信息手册 (3HAC027098-001) / ISO 10218-1:2025《工业机器人 安全要求 第1部分：机器人》
- **作者/机构**：ABB Robotics / International Organization for Standardization (ISO)
- **日期**：2026-08-11
- **权威等级**：A
- **领域标签**：K1_初学者误区
- **摘要**：介绍工业机器人初学者常见的操作误区，包括认知陷阱、操作错误及安全意识不足等问题，帮助学习者避免常见问题，参照 ABB 安全手册及 ISO 国际标准。

---

## 正文

### 1. 认知陷阱

| 误区 | 说明 | 正确认识 |
|------|------|----------|
| **设备代差陷阱** | 教学设备与企业实际设备存在技术代差，操作界面和编程逻辑可能不同 | 学习核心原理，具体操作需针对实际设备学习 |
| **虚拟化陷阱** | 依赖仿真软件，缺少真实物理环境验证，无法处理现场复杂情况 | 仿真与实操结合，多进行实体设备练习 |
| **理论堆砌陷阱** | 强调知识点的完整性，忽视实际工程问题解决能力 | 注重实践，边做边学 |

### 2. 操作速度设置错误

| 品牌 | 首次运行要求 | 说明 |
|------|-------------|------|
| **FANUC** | 10% 以下 | 首次运行新程序时必须将速度倍率调至10%以下 |
| **ABB** | 25% 以下 | 首次运行新程序时速度倍率设置不高于25% |

**常见错误**：直接以100%速度运行新程序，容易造成碰撞或设备损坏。

### 3. 坐标系相关错误

| 错误类型 | 正确做法 |
|----------|----------|
| 坐标系未校准 | 每次更换工具后必须重新标定 |
| 示教位置不准确 | 使用尖点对准参照物，反复验证 |
| 忽略负载参数 | 必须正确设置工具质量和重心 |

### 4. 程序操作错误

| 错误类型 | 正确做法 |
|----------|----------|
| 程序未保存 | 编程完成后及时保存，备份 |
| 单步未验证直接连续运行 | 先单步试运行，确认无误后再连续运行 |
| PP未移至main | 运行程序前确认程序指针在main例行程序起点 |

### 5. ABB 特有操作误区

| 误区 | 说明 | 正确做法 |
|------|------|----------|
| 忘记按住使能键 | Deadman 三段式安全机制，松开/完全按下立即停机 | 移动过程全程保持半按状态 |
| 忽略碰撞预判功能 | 双臂协调作业前必须开启 Collision Avoidance | 协调作业前确认功能已开启 |
| 负载参数设置错误 | 导致导通拖拽模式手臂僵硬、推拉阻力大 | 修正有效负载参数 |

### 6. 使能键使用误区

**问题**：手动模式松开使能开关机器人立刻停机

**原因**：Deadman 三段式安全机制正常特性，属于保护设计

**正确做法**：
- 调试期间无需移动机器人时，及时松开使能开关
- 移动过程保持半按状态

### 7. 安全意识不足

| 禁止行为 | 说明 |
|----------|------|
| 无证操作 | 没经过培训的人员，禁止操作机器人 |
| 离开现场 | 机器人运行过程中，严禁操作者离开现场 |
| 进入工作区域 | 机器人在运营和等待中，绝不可进入工作区域 |
| 急停回路违规 | 不可短接、屏蔽急停安全回路 |

### 8. 示教操作误区

| 误区 | 正确做法 |
|------|----------|
| 背对机器人 | 始终从机器人前方观察 |
| 忽略安全装置 | 进入围栏前确认安全装置位置 |
| 无退路操作 | 确保紧急情况下有退路 |
| 佩戴手套操作示教盘 | 操作示教盘时禁止戴手套 |

### 9. 调试流程误区

**正确调试流程**：
```
1. 复位准备 → 控制柜上电，复位全部急停按钮
2. 模式切换 → 切换至手动限速模式
3. 电机上电 → 按住使能键
4. 程序载入 → 打开程序编辑器加载程序
5. PP移至main → 确认程序指针位置
6. 单步试运行 → 开启单步执行模式
7. 连续运行验证 → 单步无异常后关闭单步
8. 自动模式切换 → 确认现场无人后切换
```

**常见错误**：跳过单步试运行直接连续运行，容易造成碰撞事故。

### 10. 常见问题与解决

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| 按下急停复位后无法电机上电 | 多处急停未全部复位、安全门回路断开、系统残留故障报警 | 逐一检查所有急停装置，确认安全围栏门关闭；查看示教器事件日志排查 |
| 标定误差过大 | 参考点选择不当或示教不准确 | 选择更稳定的参照点，重新示教 |
| 运动轨迹偏差 | 用户坐标系设置错误 | 验证坐标系数据，必要时重新标定 |

### 11. 紧急情况处理误区

**错误做法**：
- 发生碰撞后直接强行推拉机器人
- 人员被困时直接移动机器人
- 火灾时使用水或干粉灭火器对电控柜

**正确做法**：
- 先按下急停，再使用抱闸释放工具缓慢挪动机械臂
- 设备起火时切断总电源，使用 CO₂ 灭火器
