## 正文

### 1. FANUC 工具坐标系 (UTOOL1 基本概念

- **默认UTOOL**：原点位于J6轴法兰中心
- **可定义数量**：最多10个工具坐标系 (UTOOL 0-9)
- **UTOOL 0**：系统默认，不可更改

2 设置方法

| 方法 | 适用场景 | 操作要点 |
|------|----------|----------|
| **三点法** | 确定TCP位置 | 示教原点、X方向点、Y方向点 |
| **六点法** | 需要姿态标定 | 三个方向点 + 三个姿态点 |
| **直接输入法** | 已知坐标数据 | 直接输入X, Y, Z, W, P, R值 |

3 操作步骤

```
MENU → SETUP → Frames → Tool Frame
```

1. 进入工具坐标系设置界面
2. 选择要设置的工具号（1-9）
3. 选择标定方法（三点法/六点法/直接输入）
4. 按照提示示教各参考点
5. 保存标定结果

### 2. FANUC 用户坐标系 (UFRAME)

1 基本概念

- **可定义数量**：最多9个用户坐标系 (UFRAME_NUM 0-9)
- **UFRAME 0**：系统默认，不可更改
- **坐标系调用指令**：
  - `UTOOL_NUM` - 调用工具坐标系
  - `UFRAME_NUM` - 调用用户坐标系

2 设置方法

| 方法 | 适用场景 | 操作要点 |
|------|----------|----------|
| **三点法** | 一般标定 | 示教原点、X方向点、Y方向点 |
| **直接输入法** | 已知偏移数据 | 输入X, Y, Z, W, P, R值 |

3 三点法标定步骤

1. **示教原点**：将机器人移动到用户坐标系原点位置
2. **示教X方向点**：沿X轴正方向移动到参考点
3. **示教Y方向点**：沿Y轴正方向移动到参考点
4. **保存坐标系数据**

### 3. 坐标系调用指令

```tp
UTOOL_NUM=1    ! 调用工具坐标系1
UFRAME_NUM=1   ! 调用用户坐标系1
```

### 4. 工具坐标系标定原理

三点法标定原理：
- **原点**：TCP到达的第一个参考点
- **X方向点**：确定X轴正方向
- **Y方向点**：结合原点确定XY平面，计算Z轴方向

六点法标定原理：
- 在三点法基础上增加姿态标定点
- 可以标定工具的完整姿态（绕X、Y、Z轴的旋转）

### 5. 坐标系设置注意事项

| 注意事项 | 说明 |
|----------|------|
| 工具更换后需重新标定 | 每次更换末端执行器后必须重新标定TCP |
| 标定精度 | 误差一般允许0.5mm以内 |
| 参考点选择 | 应选择稳定、可重复定位的参照物 |
| 负载数据 | 标定完成后需输入正确的负载数据 |

### 6. 常见问题与解决

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| 标定误差过大 | 参考点选择不当或示教不准确 | 选择更稳定的参照点，重新示教 |
| 工具位置不准确 | TCP定义错误 | 检查UTOOL数据，必要时重新标定 |
| 运动轨迹偏差 | 用户坐标系设置错误 | 验证UFRAME数据，重新标定 |
