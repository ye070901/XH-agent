## 正文

### 1. 视觉引导取放的组成

视觉引导取放系统的典型链路：

```
相机抓图 → 定位目标（模板匹配/形状匹配）→ 得到像素坐标(像素)
   → 手眼/标定(像素→机器人坐标) → 机器人移动到抓取位姿 → 抓取与放置
```

相机可以为"眼在手外"（固定安装）或"眼在手上"（装在机器人末端）。固定相机引导平面取放时，通常只需要一次"像素→机器人平面坐标"的标定；装在末端的相机则还需要考虑相机随机器人位姿的变化。

### 2. 相机与系统安装

以 ABB Integrated Vision 为例，其画面处理在机器人控制器内完成，支持通过 RobotStudio 连接相机、配置视觉参数与标定：

- 相机连接控制器（如经服务口交换机），控制器/工作室中识别并添加传感器；
- 设置触发方式，使抓图与机器人动作节拍同步；
- 安装时保证相机固定稳固、工作距离与视场符合目标范围；
- 机器人末端（若装相机）需注意线缆管理与工具载荷校准。

### 3. 标定：像素坐标到机器人坐标

平面取放标定的核心是建立图像坐标系到机器人工作平面坐标系的变换（常见为仿射/透视单应变换）：

1. 在机器人可达的平面上选取已知机器人坐标的特征点（如标定板格点或靶点）；
2. 机器人逐个移动到这些点，或用固定相机对已知位置的靶点成像，采集多组"像素坐标-机器人坐标"对应；
3. 解算单应矩阵或仿射矩阵（两个坐标系由旋转、平移和缩放构成时）；
4. 用未参与拟合的点验证标定残差，不合格则重采补点。

### 4. 取放路径与纠偏

- 视觉给出的抓取点应转换为机器人安全接近方向上的"抓取预对位点+抓取点"；
- 目标有旋转时，机器人对应调整末端姿态（绕法线旋转补偿角）；
- 抓取后放置位置固定时，应复算补偿后的放置路径，避免末端转角导致碰撞；
- 节拍中先做可达性与碰撞检查，再执行取放。

### 5. 验证与常见问题

| 现象 | 原因与对策 |
|------|------------|
| 抓取整体偏移 | 标定残差大，重采点/重新标定 |
| 抓取随位置漂移 | 相机松动/视野畸变未校正，先内参标定再手眼标定 |
| 旋转补偿不准 | 成像平面与机器人平面不平行，校正安装角度 |
| 偶发误定位 | 模板鲁棒性不足，补模板/换形状匹配 |

验收：在目标随移动范围内抽检 N 个位置，机器人实际抓取误差在公差内且重复精度稳定；任何相机位置变更后必须重新标定。
