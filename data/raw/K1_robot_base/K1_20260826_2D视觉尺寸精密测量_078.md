## 正文

### 1. 2D 测量的原理

2D 视觉测量通过检测目标边缘并计算几何量（长度、宽度、直径、孔距、角度）来实现。核心是"沿测量方向提取边缘点，再对边缘点做几何拟合与求交"。HALCON 的 1D 测量（卡尺）在矩形或环形弧区域内，沿垂直方向对灰度做切片平均得到一维边缘剖面，再以亚像素位置提取边缘点。

### 2. 卡尺测量与测量模型

| 工具 | 说明 | 典型算子 |
|------|------|----------|
| 卡尺测量（1D Measuring） | 沿测量线找边缘点，适合直线、宽度、简单测量 | `gen_measure_rectangle2`、`measure_pos` |
| 测量模型（Metrology） | 同时拟合多条直线/圆弧，结构化管理 | `create_metrology_model` 系列 |
| 几何拟合 | 对边缘点拟合线/圆，控制拟合精度 | `fit_line_contour_xld` 等 |

HALCON 中 `measure_pos` 返回垂直于矩形主轴的直边缘位置，包含亚像素边缘点坐标，可在一次调用中检测多个边缘并排序。

### 3. 像素当量（标定）与精度

测量必须将像素距离换算为物理尺寸：

```
像素当量(mm/像素) = 已知物理长度 / 对应像素长度
```

获取方式：用高精度标定板在工件平面成像，标定内参并得到物面比例；或直接测量已知尺寸工件计算当量。更高精度的做法是用相机标定建立物平面坐标，消除透视带来的比例不一致。米尺级测量建议校验环境温度、工件平面是否与成像面平行。

### 4. 可执行验证思路（HALCON 风格伪流程）

1. 读取图像，进行必要的畸变校正（`change_radial_distortion_image`）；
2. 生成测量矩形或测量模型，指定方向与测量范围；
3. 执行 `measure_pos` / 拟合得到边缘与几何参数；
4. 换算为物理尺寸并与公差比较，输出判定；
5. 用标准量具标定的工件对比测量误差，验证重复精度（如 ±0.02 mm 内）。

### 5. 常见问题与验收

| 问题 | 原因与对策 |
|------|------------|
| 测量值系统性偏大/偏小 | 像素当量不准确，重新标定 |
| 测量抖动 | 边缘对比度不稳，改善照明或参数 |
| 边缘捕捉到杂点 | 测量区域过大，收紧 ROI 并设置边缘极性/阈值 |
| 不同位置测量不一致 | 透视与畸变，做相机标定与物面校正 |

验收：测量值与计量器具比对在公差范围内；同一工件重复测量标准差满足工艺要求；测量节拍满足产线要求。
