## 正文

### 1. 示教器基本操作

ABB FlexPendant 示教器是操作机器人的核心人机界面。主要按键布局如下：

- **SHIFT** 键：示教器侧边三段式安全按键，按住方可电机上电
- **F1~F5** 功能键：功能软键，对应屏幕底部菜单
- **急停按钮**：红色蘑菇头按钮，位于示教器右上角
- **Deadman 开关**：JOG 手动移动机器人各轴

**操作前安全注意事项**：
1. 进入机器人工作区域前，必须按下急停按钮
2. 首次运行新程序时，速度倍率调至 25% 以下
3. 确认工作区域内无人后方可执行自动运行

### 2. 运动指令类型

ABB IRC5 机器人支持三种基础运动指令：
表格
指令	    全称	   运动方式	     适用场景
|--------|--------|-----------|-------------------------------------------------|
MoveJ    Joint     Movement	  各关节独立运动，路径不可控	空行程、无碰撞风险的快速移动
MoveL	   Linear    Movement	  末端沿直线运动	抓取、放置、涂胶等需要精确直线路径场景
MoveC	   Circular  Movement	  末端沿圆弧运动	圆弧焊缝、圆形打磨、弧形轨迹作业

### 3. 点位示教步骤

以搬运作业为例，完整操作流程：

程序名：K1_PICK_PLACE
==================================

1.创建程序模块
  -示教器点击【程序编辑器】→【新建】
  -输入模块名称：K1_PICK_PLACE
  -程序类型：RAPID 模块

2.示教取料点 (pPick)
  -手动模式下将机器人移动到取料位置
  -光标定位代码行 → 点击【修改位置】保存点位 pPick

3.示教取料安全上方点 (pPickSafe)
  -将 Z 轴升高 100mm
  -点击【修改位置】保存点位 Offs (pPick,0,0,100)

4.示教放料点 (pPlace)
  -移动机器人到放料位置
  -点击【修改位置】保存点位 pPlace

5.示教原点安全点 (pHome)
  -移动机器人至待机原点
  -点击【修改位置】保存点位 pHome

4. RAPID 基础程序示例
rapid
MODULE K1_TestProgram
    CONST robtarget pHome:=[[0,0,800],[1,0,0,0],[-1,0,0,0],0];
    CONST robtarget pPick:=[[300,200,150],[0,0,1,0],[-1,0,0,0],0];
    CONST robtarget pPlace:=[[300,-200,150],[0,0,1,0],[-1,0,0,0],0];
    PROC main()
        MoveJ pHome,v1000,z100,tool0;
        MoveJ Offs(pPick,0,0,100),v800,z50,tool0;
        MoveL pPick,v300,fine,tool0;
        SetDO do_grip,1;
        WaitTime 0.2;
        MoveL Offs(pPick,0,0,100),v300,z50,tool0;
        MoveJ Offs(pPlace,0,0,100),v800,z50,tool0;
        MoveL pPlace,v300,fine,tool0;
        Reset do_grip;
        WaitTime 0.2;
        MoveL Offs(pPlace,0,0,100),v300,z50,tool0;
    ENDPROC
ENDMODULE

5. 程序调试运行规范

1.复位准备
  -控制柜上电，复位全部急停按钮
  -模式钥匙切换至【手动限速模式】
  -持续按住示教器侧边使能键，电机上电就绪

2.程序载入
  -打开程序编辑器加载 K1_PICK_PLACE
  -PP 移至 main 例行程序起点

3.单步试运行
  -开启【单步执行】模式
  -全程观察机器人运动轨迹，规避碰撞

4.连续运行验证
  -单步无异常后关闭单步，连续运行测试节拍
  -确认 IO 动作、点位停靠无偏差

5.自动模式切换
  -全部流程验证通过
  -确认现场无人后，切换自动模式运行

### 4. 常见问题与解决方法

**Q: ABB 机器人执行 MoveL 指令时报目标位置不可达
- 原因：目标点位超出工作范围、靠近奇异点或存在关节限位冲突
- 解决：核查点位位置避开奇异区域，重新调整姿态；可增加 MoveJ 过渡点位

**Q: MoveJ 与 MoveL 如何合理选择
- 空行程、安全移动优先使用 MoveJ（运动速度更快，节拍更优）
- 需要严格控制末端路径场景（抓取、涂胶、打磨）使用 MoveL

**Q: 示教模式下摇杆拨动机器人无法移动
- 原因：使能键未按住、急停未复位、模式档位错误
- 解决：持续按住示教器三段式使能键，释放所有急停，切换至手动限速模式
