## 正文

### 1. Data Matrix 码的特点

Data Matrix（DM）是工业制造中广泛使用的二维条码，由正方形模块组成的寻址图形与数据区构成，具有以下特性：

- **高信息密度**：单位面积可承载大量字符；
- **鲁棒性**：具备纠错能力，局部污损仍可读出；
- **尺寸小、可直刻**：常用于工件激光打标，可在小面积上编码序列号、批次等；
- **适用标准**：符号特性、编码规则、纠错算法由标准规定，最新为依据；ISO/IEC 16022:2024（第 3 版）。

### 2. 识读链路

```
打标/打印生成 → 相机成像 → 定位寻址图形 → 模块采样
    → 纠错译码 → 输出数据（如 SN、批次）→ 回传机器人/上位机
```

读码的关键在于成像质量：码元最小尺寸、打印对比度、照明均匀性与镜头分辨率直接决定最小可读码密度。

### 3. 读码系统搭建要点

| 环节 | 要点 |
|------|------|
| 相机分辨率 | 保证码元在成像中占足够像素（通常 ≥2~4 像素/模块） |
| 照明 | 均匀照明、避免反光；激光打标浅色码需恰当角度 |
| 镜头工作距离 | 视场覆盖码区且码元尺寸满足采样要求 |
| 读码算法/读码器 | 工业读码器（如基于图像的读码器）内置定位、译码与纠错 |
| 通讯 | 通过 TCP/串口/IO 输出读码结果并做超时与重试处理 |

### 4. 可执行验证思路

- 用标准校验样张/已知内容码测试读码率与单次读码耗时；
- 验证不同旋转角度、倾斜与部分污损下的译码稳定性；
- 接入机器人节拍：在读码失败时做重试分支，避免机器人误动作。

### 5. 常见问题与排查

| 现象 | 可能原因 | 对策 |
|------|----------|------|
| 读不出/误读 | 码元过小、失焦、反光 | 提高分辨率、调焦、调整光源角度 |
| 部分污损即失败 | 对比度差/纠错余量不足 | 增强对比度、保证模块采样正确 |
| 读码耗时过长 | 视场过大、算法参数差 | 缩小搜索区、优化算法参数 |
| 码方向不一致 | 旋转 | 开启全向读码 |

验收：在产线典型振动、光照变化条件下读码率达工艺要求（常见目标 >99.9% 且无误读），并记录批次信息供质量追溯。
