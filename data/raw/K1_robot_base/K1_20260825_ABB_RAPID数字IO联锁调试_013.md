## 正文

### 1. 调试目标与适用边界

工业机器人抓取、上下料和机床联机时，程序不能只“发出动作”，还必须确认外部设备已经完成动作。例如夹具闭合流程应形成“关闭打开阀输出 → 接通关闭阀输出 → 等待夹紧到位输入 → 允许后续工序”的闭环。若只使用固定 `WaitTime`，夹具卡滞、气压不足或传感器损坏时，程序仍可能继续运行，造成掉件或碰撞。

ABB 官方 RAPID 技术参考手册规定：`SetDO` 用于改变数字输出；带 `\Sync` 参数时，程序会等待输出信号被物理设置为指定值。`WaitDI` 用于等待数字输入达到目标值；配置 `\MaxTime` 后可以限制最长等待时间，配合 `\TimeFlag` 可在超时时把布尔变量置为 `TRUE`，由程序执行受控处置。需要注意，`SetDO \Sync` 只能确认输出通道已写入，并不能证明气缸、夹爪或机床已经动作到位，实际到位仍要由独立输入信号确认。

本文依据 RobotWare 6.06 技术手册编写，适用于 IRC5/RW6 的基础调试。OmniCore/RW7 或不同 RobotWare 版本应在部署前用对应版本手册复核指令选项和界面路径。

本文只讨论普通工艺 I/O。急停、安全门、使能装置、安全速度等安全功能必须使用经过风险评估和验证的安全回路或安全控制系统，不得用普通 DI/DO 替代、屏蔽或强制旁路。

### 2. 示例信号表

以下名称需要先在控制器 I/O 配置中建立，并映射到真实或虚拟 I/O 设备；现场项目的地址、有效电平和名称应以电气图纸为准。

| 信号名 | 类型 | 含义 | 正常判据 |
|---|---|---|---|
| `diCycleStart` | DI | 外部启动请求 | 1 表示允许执行一次测试 |
| `diPartPresent` | DI | 工件存在 | 夹紧前必须为 1 |
| `diClampClosed` | DI | 夹具闭合到位 | 关闭动作后应在限定时间内变为 1 |
| `diClampOpened` | DI | 夹具打开到位 | 打开动作后应在限定时间内变为 1 |
| `doClampClose` | DO | 关闭电磁阀命令 | 与打开命令互斥 |
| `doClampOpen` | DO | 打开电磁阀命令 | 与关闭命令互斥 |

### 3. 完整操作步骤

1. **备份与能量控制**：备份当前系统和程序；按照现场风险评估执行锁定、挂牌及分阶段送能，确认机器人工作区无人，并由有权限的调试人员执行。首次验证优先使用 RobotStudio 虚拟控制器；真机使用手动模式和现场规定的低速设置。
2. **核对映射**：在 I/O 配置中逐项核对信号名称、类型、设备地址和有效电平。若输出配置了反相，RAPID 逻辑值与物理通道电平可能相反，必须以电气图纸和实测结果为准。
3. **验证输入**：在示教器 I/O 监视界面观察输入。分别触发工件、打开到位和闭合到位传感器，确认只有对应 DI 改变。`diClampClosed` 与 `diClampOpened` 同时为 1 时应停止调试并检查传感器安装、接线或映射。
4. **验证输出**：确认人员和工具均离开危险区域后，以单个输出为单位测试。接通 `doClampClose` 时不得同时接通 `doClampOpen`；核对实际阀动作、指示灯及输入反馈。示教器中的模拟输入只能用于程序逻辑测试，不能代替真机验收。
5. **载入程序**：将下列模块载入 RAPID 任务。确认六个信号已存在后，把程序指针移到 `main`，先单步执行，再执行连续测试。程序本身不含机器人运动指令，只测试 I/O 请求、互锁、到位反馈和超时处理。
6. **记录结果**：保存 I/O 监视或 Signal Analyzer 的时间记录，并记录事件日志中的错误号、发生时间和最后一个有效信号，为后续故障定位提供依据。

### 4. 可执行 RAPID 示例

```RAPID
MODULE K1_IO_INTERLOCK
    VAR bool bFault := FALSE;
    VAR bool bTimeout := FALSE;

    PROC AllOutputsOff()
        SetDO \Sync, doClampClose, 0;
        SetDO \Sync, doClampOpen, 0;
    ENDPROC

    PROC CloseClamp()
        bTimeout := FALSE;

        IF diPartPresent = 0 THEN
            bFault := TRUE;
            TPWrite "E101: part not present";
            RETURN;
        ENDIF

        ! 两个方向的阀输出必须互斥
        SetDO \Sync, doClampOpen, 0;
        SetDO \Sync, doClampClose, 1;

        ! 等待真实的闭合到位反馈，最长 3 秒
        WaitDI diClampClosed, 1\MaxTime:=3\TimeFlag:=bTimeout;
        IF bTimeout THEN
            bFault := TRUE;
            AllOutputsOff;
            TPWrite "E102: clamp close timeout";
        ENDIF
    ENDPROC

    PROC OpenClamp()
        bTimeout := FALSE;
        SetDO \Sync, doClampClose, 0;
        SetDO \Sync, doClampOpen, 1;

        ! 等待真实的打开到位反馈，最长 3 秒
        WaitDI diClampOpened, 1\MaxTime:=3\TimeFlag:=bTimeout;
        IF bTimeout THEN
            bFault := TRUE;
            AllOutputsOff;
            TPWrite "E103: clamp open timeout";
        ENDIF
    ENDPROC

    PROC main()
        bFault := FALSE;
        bTimeout := FALSE;
        AllOutputsOff;

        ! 启动请求同样设置超时，避免无限等待
        WaitDI diCycleStart, 1\MaxTime:=30\TimeFlag:=bTimeout;
        IF bTimeout THEN
            bFault := TRUE;
            TPWrite "E100: start request timeout";
        ENDIF

        IF bFault THEN
            AllOutputsOff;
            Stop;
            RETURN;
        ENDIF

        CloseClamp;
        IF bFault THEN
            AllOutputsOff;
            Stop;
            RETURN;
        ENDIF

        WaitTime 0.5;
        OpenClamp;
        IF bFault THEN
            AllOutputsOff;
            Stop;
            RETURN;
        ENDIF

        AllOutputsOff;
        TPWrite "I/O interlock test passed";
    ENDPROC
ENDMODULE
```

### 5. 结果判定与故障排查

正常流程应依次出现启动输入、关闭输出、闭合到位输入、打开输出、打开到位输入，最后两个阀输出均回到 0。若程序停在 `WaitDI`，不要直接把输入强制为 1 后投入生产，而应按以下顺序排查：

1. **控制器层**：确认 I/O 单元在线。出现 `ERR_NORUNUNIT` 时检查设备通信和供电；出现 `ERR_SIG_NOT_VALID` 时检查设备状态及 I/O 配置；出现 `ERR_NO_ALIASIO_DEF` 时检查 RAPID 信号变量是否正确关联到已配置的 I/O 信号。
2. **逻辑层**：确认程序等待的值与有效电平一致，并检查是否存在同一周期内重复写输出、输出互斥遗漏或信号反相。`SetDO` 未带 `\Sync` 时，下一条指令可在物理输出完成前继续执行，这也是时序问题的常见来源。
3. **电气层**：用电气图纸核对端子、通道地址、24 V 电源、继电器和阀线圈；确认传感器信号确实到达控制器，而不是只在现场指示灯上变化。
4. **机械层**：若输出正确而反馈超时，检查气压、夹具卡滞、工件偏移、传感器间隙和机械限位。排除机械故障后再复位程序指针并重新测试。

调试合格的最低条件是：信号映射与图纸一致；打开和关闭输出互斥；每个外部动作都有独立到位反馈；所有等待均有超时出口；超时后输出进入项目风险评估所定义的状态；虚拟测试与真机低速测试均留有记录。
