# 06 对照 · 画像预期 vs 系统实测
本组用例在 `data/evaluation/learner_profiles.json` 中预先定义了「应得难度 / 风格」真值，用于客观评估适配准确率。

| 项 | 预期（真值） | 系统实测 |
|----|------|------|
| 难度 | beginner | beginner |
| 学习风格 | visual | visual |

**难度预期依据**：无任何工业/电气/机械背景，前置测试仅 5/120，需从最基础的概念与直观认识起步。

**风格预期依据**：零基础学习者最需要图像、视频、动画等可视化手段建立直观认识。
