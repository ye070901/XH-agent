# 01 知识库切片 · 工业机器人编程与调试

> 对应题目提交要求：**「至少 1 个垂直领域的专业知识库切片（用于检索的领域文档或实操数据）」**

## 一、切片是什么

本切片是「工业机器人编程与调试」领域（FANUC / KUKA / ABB 多品牌）的核心知识库子集：
从全量 235 篇领域文档中，按 `data/core_knowledge_map.json` 的 **21 个 core 级核心知识点**
逐一挑选权威源文档，共 **27 篇**，物理存放于 `kb_slice/` 目录。

选取原则：
- 每个 core 知识点至少 1 篇权威文档，优先选「实操 + 故障处置」类（非纯理论泛文）；
- 文档即知识库检索（ChromaDB）的原始语料，切片与生产语料同源，非二次改写。
