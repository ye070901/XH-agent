# FANUC SRVO-105 故障代码解析与处理指南

- 来源：[FANUC Corporation 官方手册入口](https://www.fanuc.co.jp/en/support/manual)；故障定义与处理依据为《R-30iB Controller Maintenance Manual》B-83195EN/08。

- 日期：2026-08-07
- 权威等级：A
- 领域标签：K3_安全规范、K3_故障诊断
- 摘要：解析 FANUC 机器人常见故障代码 SRVO-105（Door open or E-Stop）的含义、控制柜门开关与急停回路排查顺序、安全复位边界和产线恢复要求，适用于 R-30iB 控制器安全链路相关停机的现场诊断。

## 正文

### 1. 故障代码概述

| 字段 | 内容 |
| --- | --- |
| 故障代码 | SRVO-105 |
| 故障名称 | Door open or E-Stop（控制柜门打开或急停） |
| 手册定义 | 控制柜门处于打开状态；若系统未配置柜门开关，手册要求跳过柜门开关检查，转查急停单元连接。 |
| 主要影响 | 伺服无法正常使能，机器人处于安全停机状态。 |
| 重要区分 | SRVO-105 指向**控制柜门开关或控制器急停链路**。机器人工作单元的安全围栏/安全门在 R-30iB 中通常对应 Fence Open 等独立安全信号，不能直接把两者当作同一故障。 |

### 2. 常见原因分析

R-30iB 维护手册给出的检查顺序如下：

1. **控制柜门未关好**
   - 配置柜门开关的控制器，柜门打开时会触发该报警。
   - 应先确认门已完全关闭、门锁和机械配合正常。

2. **柜门开关或连接电缆故障**
   - 门开关触点损坏、位置偏移、连接器松脱或电缆故障。
   - 该项只适用于原本安装了柜门开关的系统。

3. **急停单元与伺服放大器之间的连接异常**
   - 手册要求检查急停单元上的 CRMA92、CRMA94（A-cabinet）或 CRMA74（B-cabinet），以及伺服放大器上的 CRMA91 是否牢固连接。
   - 连接器虚接、插头未锁紧或维修后错接均可能造成报警。

4. **急停板或六轴伺服放大器故障**
   - 在门开关和连接回路确认正常后，手册将急停板、六轴伺服放大器列为后续更换对象。

> SRVO-105 是安全功能相关报警。不得用短接、旁路或强制信号的方法让机器人恢复运行；这会破坏设计的安全功能，并可能使人员暴露于未预期的机器人运动风险。

### 3. 故障诊断流程

```text
发生 SRVO-105 / Door open or E-Stop
    ↓
1. 保持安全停机状态
   → 不复位、不强制伺服使能、不旁路安全回路
    ↓
2. 确认人员已离开危险区，按现场程序检查控制柜门
   → 若配置门开关：确认柜门关闭、门锁可靠啮合
   → 若未配置门开关：跳过本项，直接检查急停单元连接
    ↓
3. 检查门开关及其连接电缆（仅限配置门开关的系统）
   → 检查开关机械状态、插头、电缆与端子
   → 损坏件按原安全等级和机型要求更换
    ↓
4. 断电并按手册检查急停链路连接器
   → E-STOP 单元：CRMA92、CRMA94（A-cabinet）或 CRMA74（B-cabinet）
   → 伺服放大器：CRMA91
    ↓
5. 恢复原始连接并上电复查报警
   → 报警持续时，按维修手册由授权人员诊断急停板
   → 再考虑更换六轴伺服放大器
    ↓
6. 安全复机验证
   → 验证柜门、急停、围栏/门锁及模式切换均按设计动作
   → 在空载、低风险条件下完成受控启动后，恢复生产
```

### 4. 处理方法

**现场处理：**

1. 关闭控制柜门；若门开关系统已安装，确认门开关动作可靠且电缆、连接器无松脱或损伤。
2. 对控制器进行断电隔离后，按当前控制柜型号检查并重新固定手册指定的急停单元和伺服放大器连接器。
3. 若连接检查无异常而报警持续，按手册顺序由合格维修人员更换或检测急停板，必要时再处理六轴伺服放大器。

**安全复机要求：**

1. 排故后应分别验证控制柜门开关、示教器急停、操作面板急停、外部急停及工作单元安全围栏/门锁的停机功能。
2. 不得将柜门开关与安全围栏回路混接，也不得根据其他控制器型号的端子号修改本机接线。
3. 仅在所有安全信号恢复正常、危险区确认无人、模式选择正确且产线许可条件满足后，才能重新使能伺服和恢复自动运行。

**恢复边界：**

- 不允许为赶产量而短接门开关、急停或围栏安全回路。
- 若需要更改安全接线、门锁或安全逻辑，应由具备安全控制系统设计权限的人员依据设备风险评估、当地法规及适用安全标准完成验证。
- 任何安全功能维修后，都应记录测试结果和复机批准信息。

### 5. 预防措施

1. 将控制柜门锁、门开关、急停按钮、急停连接器和安全回路功能测试纳入点检计划。
2. 维修、搬运或清洁控制柜后，检查 CRMA91、CRMA92、CRMA94/CRMA74 等连接器是否回装到位；具体连接器以控制柜型号为准。
3. 对安全链路的改造实行图纸、变更记录和双人复核，避免接线错误或未经批准的临时旁路遗留在现场。
4. 产线恢复前执行安全功能验证和受控启动，确认安全门/围栏、急停和模式切换均能产生预期停机响应。

## 适用场景

本文可用于 XH-agent 系统的安全停机报警分流、控制柜维护指导、安全互锁检查和产线复机流程。对于 R-30iB，SRVO-105 主要用于定位控制柜门及急停单元链路；工作单元安全围栏故障应依据实际报警和安全回路图纸另行诊断。
