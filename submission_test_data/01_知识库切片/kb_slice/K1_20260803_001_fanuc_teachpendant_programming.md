## 正文

### 1. 示教器基本操作

FANUC 示教器（Teach Pendant, TP）是操作机器人的核心人机界面。主要按键布局如下：

- **SHIFT** 键：配合其他按键启用运动或程序执行
- **F1~F5** 功能键：对应屏幕底部菜单
- **急停按钮**：红色蘑菇头按钮，位于示教器右上角
- **Deadman 开关**：示教器背面的三段式安全开关

**操作前安全注意事项**：
1. 进入机器人工作区域前，必须按下急停按钮
2. 首次运行新程序时，速度倍率调至 10% 以下
3. 确认工作区域内无人后方可执行自动运行

### 2. 运动指令类型

FANUC 机器人支持三种基本运动指令：

| 指令 | 全称 | 运动方式 | 适用场景 |
|------|------|----------|----------|
| PTP | Point-to-Point | 各关节独立运动，路径不可控 | 空行程、无碰撞风险的快速移动 |
| LIN | Linear | 末端沿直线运动 | 焊接、涂胶等需要精确路径的场景 |
| CIRC | Circular | 末端沿圆弧运动 | 圆弧焊缝、圆形轨迹 |

### 3. 点位示教步骤

以搬运作业为例，完整操作流程：

```
程序名: PICK_PLACE
==================================

1. 创建程序
   - 按 SELECT → 选择 "创建新程序"
   - 输入程序名: PICK_PLACE
   - 选择程序类型: TP

2. 示教取料点 (P[1])
   - 手动模式下将机器人移动到取料位置
   - 按 POINT 键 → 输入位置编号 1
   - 确认后按 ENTER 保存

3. 示教取料上方点 (P[2])
   - 先将 Z 轴升高 100mm
   - 按 POINT → 输入 2 → ENTER

4. 示教放料点 (P[3])
   - 移动机器人到放料位置
   - 按 POINT → 输入 3 → ENTER

5. 编写程序
   ```tp
   1: J P[2] 100% FINE       // 移动至取料上方
   2: L P[1] 500mm/s FINE    // 直线下降至取料点
   3: RO[1]=ON               // 夹爪闭合
   4: WAIT 0.50(sec)         // 等待夹爪闭合
   5: L P[2] 500mm/s FINE    // 直线提升
   6: J P[3] 100% FINE       // 关节移动至放料上方
   7: L P[4] 500mm/s FINE    // 直线下降至放料点
   8: RO[1]=OFF              // 夹爪松开
   9: WAIT 0.50(sec)         // 等待夹爪松开
   10: L P[3] 500mm/s FINE   // 直线提升至安全高度
   ```

### 4. 常见问题与解决方法

**Q: 机器人执行 LIN 指令时报 "不可达" 错误**
- 原因：目标点超出工作空间或关节限位
- 解决：检查目标点是否在工作空间内，调整机器人姿态

**Q: PTP 与 LIN 如何选择**
- 空行程优先使用 PTP（速度快、对机器人磨损小）
- 需要精确路径的工序（焊接、涂胶）使用 LIN
