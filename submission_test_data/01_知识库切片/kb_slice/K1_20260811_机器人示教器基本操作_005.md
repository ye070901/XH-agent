## 正文

### 1. FANUC 示教器 (Teach Pendant) 基本操作

#### 1.1 主要按键布局

FANUC 示教器（Teach Pendant, TP）是操作机器人的核心人机界面。

| 按键 | 功能 |
|------|------|
| **SHIFT** | 配合其他按键启用运动或程序执行 |
| **F1~F5** | 对应屏幕底部菜单 |
| **急停按钮** | 红色蘑菇头按钮，位于示教器右上角 |
| **Deadman 开关** | 示教器背面的三段式安全开关 |
| **POINT** | 保存位置点 |
| **SELECT** | 程序选择/创建 |
| **ENTER** | 确认输入 |

#### 1.2 操作前安全注意事项

1. 进入机器人工作区域前，必须按下急停按钮
2. 首次运行新程序时，速度倍率调至 **10% 以下**
3. 确认工作区域内无人后方可执行自动运行

### 2. ABB FlexPendant 示教器基本操作

#### 2.1 主要按键布局

ABB FlexPendant 示教器是 IRC5 控制器配套操作终端。

| 按键/组件 | 功能 |
|-----------|------|
| **SHIFT** | 示教器侧边三段式安全按键，按住方可电机上电 |
| **F1~F5** | 功能软键，对应屏幕底部菜单 |
| **急停按钮** | 红色蘑菇头按钮，位于示教器右上角 |
| **Deadman 开关** | JOG 手动移动机器人各轴 |
| **快速设置菜单** | 一键切换机械臂、坐标系、运动模式 |

#### 2.2 操作前安全注意事项

1. 进入机器人工作区域前，必须按下急停按钮
2. 首次运行新程序时，速度倍率调至 **25% 以下**
3. 确认工作区域内无人后方可执行自动运行
4. 随身携带示教器

### 3. 操作模式对比

| 品牌 | 手动模式 | 自动模式 | 说明 |
|------|---------|---------|------|
| **FANUC** | T1/T2 | AUTO | T1/T2为手动限速模式 |
| **ABB** | 手动限速模式 | 自动模式 | 需钥匙切换 |

### 4. 动作模式 (手动模式下)

| 模式 | 说明 | 用途 |
|------|------|------|
| **单轴模式** | 单独控制每个关节轴(1-6轴) | 调整机器人姿态，避免奇异点 |
| **线性模式** | TCP沿直线运动 | 直线移动、精确到位 |
| **重定位模式** | TCP位置不变，只改变工具姿态 | 调整工具角度 |

### 5. ABB IRB14000 双臂协作机器人示教器特点

IRB14000（YuMi）配套 FlexPendant 手持示教器，专用功能：

| 功能 | 说明 |
|------|------|
| **三段式 Deadman 使能开关** | 示教器背部，仅全程按住方可电机上电、手动微动 |
| **快速设置菜单快捷键** | 一键切换机械臂 ROB_L/ROB_R、坐标系、运动模式 |
| **Jog 微动窗口** | 切换单轴 / 线性 / 手臂协调微动模式，查看各轴角度实时读数 |

**IRB14000 专用安全注意事项**：
1. 进入机器人作业区域前按下急停，确认双臂无干涉工装
2. 首次调试程序速度倍率限制 25% 以内，禁止 100% 速度试运行
3. 双臂协调作业前必须开启 Collision Avoidance 碰撞预判功能
4. 导通拖拽模式使用前需正确设置工具有效负载参数

### 6. 示教器使用规范

| 要求 | 说明 |
|------|------|
| 操作人员 | 严禁非专业人员手动操作 |
| 防护用品 | 操作示教盘时禁止戴手套 |
| 速度控制 | 采用较低倍率速度进行点动操作 |
| 示教器存放 | 用完后须放回原处 |
| 观察位置 | 始终从机器人前方观察，不背对作业 |

### 7. FANUC 程序调试运行规范

```
1. 控制柜上电，复位全部急停按钮
2. 模式钥匙切换至【手动限速模式】
3. 持续按住示教器使能键，电机上电就绪
4. 单步试运行，全程观察机器人运动轨迹，规避碰撞
5. 连续运行验证，确认 IO 动作、点位停靠无偏差
```

### 8. ABB 程序调试运行规范

```
1. 复位准备：控制柜上电，复位全部急停按钮
2. 模式切换：模式钥匙切换至【手动限速模式】
3. 电机上电：持续按住示教器侧边使能键
4. 程序载入：打开程序编辑器加载程序
5. PP移至 main 例行程序起点
6. 单步试运行：开启【单步执行】模式，全程观察机器人运动轨迹
7. 连续运行验证：单步无异常后关闭单步，连续运行测试节拍
8. 自动模式切换：确认现场无人后，切换自动模式运行
```

### 9. 常见问题与解决

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| 示教模式下摇杆拨动机器人无法移动 | 使能键未按住、急停未复位、模式档位错误 | 持续按住示教器三段式使能键，释放所有急停，切换至手动限速模式 |
| 手动模式松开使能开关机器人立刻停机 | Deadman 三段式安全机制正常特性，属于保护设计 | 调试期间无需移动机器人时，及时松开使能开关；移动过程保持半按状态 |
