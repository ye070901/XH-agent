# 工业机器人基础安全常识-操作指南

- **来源**：ABB IRC5 机器人紧急安全信息手册 (3HAC027098-001) / ISO 10218-1:2025 / ISO 10218-2:2025 / GB 11291-2011
- **作者/机构**：ABB Robotics / International Organization for Standardization (ISO) / 中国国家标准化管理委员会
- **日期**：2026-08-11
- **权威等级**：A
- **领域标签**：K1_基础安全
- **摘要**：介绍工业机器人基础安全常识，包括操作前注意事项、个人防护、作业区域安全、急停处置、紧急救援等安全规范，参照 ABB 安全手册及 ISO/GB 国际国内安全标准要求。

## 正文

### 1. FANUC 操作前安全注意事项

1. 进入机器人工作区域前，必须按下急停按钮
2. 首次运行新程序时，速度倍率调至 **10% 以下**
3. 确认工作区域内无人后方可执行自动运行

### 2. ABB FlexPendant 操作前安全注意事项

1. 进入机器人工作区域前，必须切换至手动限速模式，随身携带示教器
2. 首次运行新程序时，速度倍率设置不高于 **25%**，优先单步调试
3. 自动模式运行期间，禁止人员进入机器人运动范围
4. 出现碰撞、人员危险、设备异常，立刻按下任意一处急停按钮

### 3. 个人防护

| 要求 | 说明 |
|------|------|
| 着装 | 穿着工作服，不穿宽松衣服 |
| 首饰 | 不佩戴耳环、戒指等大首饰 |
| ESD防护 | 做好静电放电防护 |
| 防护手套 | 操作示教盘时禁止戴手套（精密操作需要触感） |

### 4. 作业区域安全

| 要求 | 说明 |
|------|------|
| 安全围栏 | 必须牢固、不可移动 |
| 状态标识 | 围栏外部清楚标示机器人所处状态 |
| 区域标线 | 地面用油漆标明危险区域 |
| 安全空间 | 留出足够安全空间供紧急躲避 |

### 5. 示教作业安全

| 要求 | 说明 |
|------|------|
| 示教位置 | 尽可能在安全围栏外进行示教 |
| 进入围栏 | 确认安全装置位置 |
| 观察角度 | 始终从机器人前方观察，不背对作业 |
| 紧急退路 | 确保紧急情况下有退路 |

### 6. ABB 紧急场景分类与处置

| 场景类型 | 处置方式 | 适用说明 |
|----------|----------|----------|
| **紧急停止（E-Stop）** | 按下急停按钮，机器人立即切断动力受控停机 | 人员遇险、轨迹干涉、意外故障通用方案 |
| **手动释放抱闸** | 使用专用释放工具松开轴抱闸，外力挪动机械臂 | 人员被机器人夹持困住时救援使用 |
| **设备起火** | 切断总电源，使用 CO₂ 二氧化碳灭火器灭火 | 禁止用水、干粉灭火器对电控柜灭火 |
| **安全回路触发停机** | 检查安全门、光栅等外设，排除风险后复位 | 属于保护性停机，非故障报警 |

### 7. ABB 急停触发完整恢复流程

```
1. 排查风险：确认造成急停的危险情况已经消除（无人员被困、无碰撞干涉）
2. 复位急停按钮：顺时针旋转示教器 / 控制柜红色蘑菇头按钮，解除自锁
3. 清除系统报警：在示教器事件日志确认急停报警消除
4. 伺服电机上电：按下控制柜「电机上电（Motors On）」按钮
5. 低速验证：以低倍率手动移动机器人，确认系统恢复正常
```

⚠️ **注意：不可短接、屏蔽急停安全回路，违反设备安全规范。**

### 8. ABB 常见安全故障与解决方法

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| 按下急停复位后无法电机上电 | 多处急停未全部复位、安全门回路断开、系统残留故障报警 | 逐一检查所有急停装置，确认安全围栏门关闭；查看示教器事件日志排查 |
| 手动模式松开使能开关机器人立刻停机 | Deadman 三段式安全机制正常特性，属于保护设计 | 调试期间无需移动机器人时，及时松开使能开关；移动过程保持半按状态 |
| 发生人员被机械臂夹持如何救援 | 意外碰撞困人 | 先按下急停，再使用抱闸释放工具缓慢挪动机械臂解救人员，禁止直接强行推拉机器人 |

### 9. 程序调试运行规范

**FANUC**:
```
1. 控制柜上电，复位全部急停按钮
2. 模式钥匙切换至【手动限速模式】
3. 持续按住示教器使能键，电机上电就绪
4. 单步试运行，全程观察机器人运动轨迹，规避碰撞
5. 连续运行验证，确认 IO 动作、点位停靠无偏差
```

**ABB**:
```
1. 复位准备：控制柜上电，复位全部急停按钮
2. 模式切换：模式钥匙切换至【手动限速模式】
3. 电机上电：持续按住示教器侧边使能键
4. 程序载入：打开程序编辑器加载程序
5. PP移至 main 例行程序起点
6. 单步试运行：开启【单步执行】模式，全程观察
7. 连续运行验证：确认 IO 动作、点位停靠无偏差
8. 自动模式切换：确认现场无人后，切换自动模式运行
```

### 10. 维护作业安全

| 要求 | 说明 |
|------|------|
| 断电操作 | 断开电源后再进行维修保养 |
| 电机上电前 | 确认电压、频率、电缆规格 |
| 接地检查 | 确保控制箱可靠接地 |

### 11. ISO 10218 标准要点

**ISO 10218-1:2025** (机器人安全要求 - 第1部分):
- 工业机器人固有安全设计
- 风险降低措施
- 作为"部分完成的机械"的要求

**ISO 10218-2:2025** (机器人安全要求 - 第2部分):
- 系统集成和调试
- 运行和维护
- 机器人单元和工作站安全

**不适用范围**:
- 水下应用
- 执法/军事应用
- 航空/航天应用
- 医疗应用

### 12. GB 11291 中国标准

GB 11291 是中国工业机器人安全要求的国家标准，等效采用国际标准 ISO 10218 的要求，规定了中国市场工业机器人的安全要求。

### 13. 安全标识

| 标识 | 含义 |
|------|------|
| 红色蘑菇头按钮 | 急停按钮，按下立即停机 |
| 黄色/黑色条纹 | 危险区域标识 |
| 安全围栏 | 禁止未经授权人员进入 |

### 14. 安全行为准则

| 准则 | 说明 |
|------|------|
| 授权操作 | 只允许经过培训的人员操作机器人 |
| 速度优先 | 调试时低速，验证后逐步提速 |
| 观察优先 | 机器人运行时保持观察 |
| 防护到位 | 进入工作区域前确认安全装置 |
