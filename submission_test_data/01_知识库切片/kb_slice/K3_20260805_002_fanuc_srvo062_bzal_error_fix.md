# FANUC SRVO-062 故障代码解析与处理指南

- 来源：[FANUC Corporation 官方手册入口](https://www.fanuc.co.jp/en/support/manual)；故障定义与处理依据为《R-30iB Controller Maintenance Manual》B-83195EN/08。
- 作者/机构：FANUC Corporation 维护手册
- 日期：2026-08-05
- 权威等级：A
- 领域标签：K3_故障诊断
- 摘要：解析 FANUC 机器人常见故障代码 SRVO-062（BZAL，脉冲编码器绝对位置备份电池报警）的含义、排查顺序、报警复位与重新标定要求，适用于一线维修和调试人员在绝对位置数据丢失后安全恢复设备。

## 正文

### 1. 故障代码概述

| 字段 | 内容 |
| --- | --- |
| 故障代码 | SRVO-062 |
| 故障名称 | BZAL（Battery Zero Alarm） |
| 手册定义 | 串行脉冲编码器的绝对位置备份电池电量已耗尽，或备份供电已丢失。 |
| 主要影响 | 机器人绝对位置数据可能丢失；排除根因后仍须执行规定的脉冲编码器报警复位和重新标定（MASTERING）。 |
| 典型关联 | SRVO-065/BLAL 是电池电压低预警；SRVO-062 表示备份已失效或绝对位置数据已无法保持，不能只按低电量预警处理。 |

### 2. 常见原因分析

SRVO-062 的排查重点是绝对位置备份回路，而不是伺服通讯链路。维护手册列出的主要检查方向如下：

1. **备份电池耗尽或未正确安装**
   - 机器人断电期间，脉冲编码器依靠备份电池保持绝对位置数据。
   - 电池耗尽、缺失或更换操作中备份中断，均可能触发该报警。

2. **电池盒及电池电缆异常**
   - 电池插头松脱、端子接触不良或电池电缆断线。
   - 手册将“电池电缆断开”或“未装电池”列为可能原因。

3. **机械单元内部备份供电电缆异常**
   - 机械单元内从电池到脉冲编码器的供电电缆断开。
   - 电缆对地短路或绝缘损坏。

4. **脉冲编码器故障**
   - 在电池及供电回路确认正常后，报警轴的脉冲编码器本体仍可能故障，需要按机型维修手册确认后更换。

> 不要把 SRVO-062 简化为“测到某个固定电压阈值就复位”。不同控制柜、电池组件和机型的检查方法不同，应以对应机械单元和控制器手册为准。

### 3. 故障诊断流程

```text
发生 SRVO-062 / BZAL
    ↓
1. 记录报警组号、轴号、报警历史和当前姿态
   → 禁止在绝对位置未恢复前直接自动运行
    ↓
2. 按现场安全程序停机并隔离能量
   → 由受过培训的人员执行电池与编码器相关作业
    ↓
3. 检查备份电池与电池盒
   → 确认电池已安装、极性/插接状态正确
   → 检查电池插头、端子和电池电缆是否松脱、破损
    ↓
4. 检查机械单元内部备份供电电缆
   → 检查从电池至脉冲编码器的供电电缆是否断开或对地短路
    ↓
5. 更换失效电池并按手册复查回路
   → 若报警仍存在，按对应机型维修手册检查或更换报警轴脉冲编码器
    ↓
6. 根因排除后复位脉冲编码器报警
   → 依控制器手册由授权人员设置 $MCR.$SPC_RESET=TRUE
   → 按规定重新上电；不要把该变量用于 SRVO-068 等非 BZAL 类报警
    ↓
7. 执行 MASTERING 并验证
   → 依机型、数据丢失范围和维修项目选择合适的标定方式
   → 低速试运行、确认位置和安全区后，方可恢复自动生产
```

### 4. 处理方法

**根因处理：**

1. 更换失效的备份电池，并修复或更换松脱、断裂、短路的电池供电电缆。
2. 检查机械单元内部电池至脉冲编码器的供电路径；确认无断开、对地短路后再进行后续操作。
3. 若备份回路正常而报警持续，按报警轴和适用机型手册更换脉冲编码器。

**报警复位与重新标定：**

1. 在故障原因已消除的前提下，FANUC 维护手册针对 SRVO-062 指示设置 `$MCR.$SPC_RESET=TRUE`，再重新接通控制器电源。
2. SRVO-062 后通常需要重新执行 **Quick Mastering**；若更换过脉冲编码器，通常需要按手册采用单轴标定或治具位置标定等适用方法。
3. 标定后先在低速、受控状态下执行测试运行，确认 TCP、软限位、工装间隙和安全区均正确，再恢复自动模式。

**恢复边界：**

- 不应仅清除报警就恢复自动生产。绝对位置数据丢失会影响机器人姿态与程序点的可信度。
- 不应以“禁用故障轴”替代绝对位置恢复；这可能破坏机构约束、碰撞防护或产线互锁逻辑。
- 电池、脉冲编码器和标定操作应由具备 FANUC 设备维护资质的人员，按当前控制器和机械单元手册执行。

### 5. 预防措施

1. 建立电池更换台账，按设备所用控制器、机械单元和电池组件的维护手册安排预防性更换。
2. 定期检查电池盒、电池插头及机械臂活动区域的备份电缆，重点关注夹伤、反复弯折和油污污染。
3. 在更换电池、脉冲编码器或进行控制器维护前，备份系统数据，并记录已验证的标定基准和当前工艺状态。
4. 电池维护完成后，在恢复自动生产前完成报警复核、标定验证和低速试运行；将结果纳入产线恢复记录。

## 适用场景

本文可用于 XH-agent 系统的 FANUC 绝对位置丢失故障排查、维修工单辅助、安全复机检查和故障代码自动诊断知识支撑。它与 SRVO-068（DTERR，串行脉冲编码器数据传输错误）形成互补：SRVO-062 优先检查备份供电与标定，SRVO-068 优先检查串行编码器通讯链路。
