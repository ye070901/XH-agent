## 正文

### 1. 机器人路径正确不等于焊接电流稳定

弧焊质量由机器人运动、焊机、电源、送丝、焊枪、工件接地回路、保护气和夹具共同决定。电流波动、飞溅增多、断弧或焊缝成形异常时，不应先改机器人路径或强行提高参数；先记录焊机报警、程序/焊接规范号、工件批次、送丝速度、气体状态和故障发生的时间位置。

### 2. 分诊表

| 类别 | 先检查的可观察项 |
| --- | --- |
| 送丝 | 丝盘制动、送丝轮压紧、导丝管阻力、焊丝污染/折弯、实际送丝是否连续 |
| 焊枪 | 导电嘴磨损/堵塞、枪颈过热、线缆弯折、碰撞后姿态和 TCP 是否变化 |
| 接地回路 | 工件夹持点、回路线连接、接触面锈蚀/油漆、回路是否经过不可靠转台或夹具 |
| 电源与规范 | 焊机状态、焊接规范/工艺包、极性、通信接口、额定负载与报警记录 |
| 干扰与布局 | 焊接动力线与弱电信号线分离、屏蔽和接地方案、拖链弯曲与连接器受力 |

### 3. 排查与恢复顺序

1. 停止自动试焊，保持通风、防护、上锁隔离和现场工艺安全措施。
2. 先查看焊机/送丝机故障和机器人/PLC 事件时间线，判断异常在起弧、稳定焊接、收弧还是移动阶段发生。
3. 从机械耗材与接地回路开始做外观和受控检查，再核对工艺规范与电源接口；每次只隔离一个变量。
4. 在经批准条件下用试板和低风险测试验证，记录波形/报警/焊缝结果；不得以“看起来能焊”代替首件质量确认。
5. 修复后复核线缆固定、枪体路径和电气布线，防止拖链运动再次造成间歇故障。

### 4. 布线原则

高电流焊接动力回路与低压信号、编码器、网络线应按项目电气规范分槽/分层并保持合理间距；屏蔽端接和接地方案必须遵循设备厂家及单元设计，不能凭经验两端随意接地。任何接地、焊机或安全回路修改都属于受控变更。
