## 正文

### 1. 选型前先定义应用目标

不同的应用对相机与镜头的要求差异很大，选型应从应用目标倒推：

| 应用 | 光学重点 | 推荐镜头方向 |
|------|----------|--------------|
| 尺寸测量 | 高精度、低畸变 | 远心镜头或高分辨率定焦镜头 |
| 缺陷检测 | 高对比、高分辨率 | 高分辨率定焦镜头 |
| 读码/字符识别 | 清晰成像 | 标准定焦镜头 |
| 定位引导 | 大视场、可覆盖工位 | 广角或标准定焦 |
| 3D轮廓 | 激光线聚焦 | 激光三角专用镜头 |

### 2. 镜头与传感器必须匹配

常见错误是镜头与传感器不匹配导致成像质量骤降：

- **像圈**：镜头像圈必须不小于传感器靶面，否则出现暗角。
- **分辨率**：镜头分辨率要能支撑传感器像素数，低分辨率镜头会拖累高像素相机。
- **像元尺寸**：小像元（如 3.45 µm 以下）需要镜头能分辨到该尺度，否则出现混叠。

### 3. 关键光学参数计算

镜头选型的核心关系式（薄透镜近似）：

```
焦距 f = 工作距离 W.D. × 传感器靶面尺寸 S / 视场宽度 FOV
```

示例：传感器靶面宽 6.4 mm（如 1/2"），要求工作距离 300 mm、视场宽 200 mm，则焦距 f ≈ 300 × 6.4 / 200 = 9.6 mm，可选用 10 mm 定焦镜头。

### 4. 相机关键参数

| 参数 | 说明 |
|------|------|
| 分辨率 | 决定单像素物理尺寸，与精度直接相关 |
| 靶面/芯片尺寸 | 决定镜头像圈匹配与视场 |
| 帧率 | 决定节拍内是否产生运动模糊 |
| 快门与曝光 | 运动工件用短曝光或频闪光源 |
| 接口 | GigE Vision / USB3 Vision / Camera Link，影响传输距离与速率 |
| 触发方式 | 硬件触发保证与机器人动作同步 |

### 5. 机器人视觉安装的建议

- 相机固定端（眼在手外）优先，可降低随动振动；装机器人末端（眼在手上）时注意线缆管理与随动质量。
- 使用频闪光源配合短曝光，减小运动模糊。
- 镜头加装保护窗，防止粉尘与飞溅损伤；定期清洁并复查对焦。
- 任何镜头或安装位置变更后，必须重新进行相机标定与手眼标定。
