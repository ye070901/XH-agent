## 2 系统生成过程

系统响应先产生学情诊断，再经过检索、生成、审核、辩论和修正等环节。以下业务步骤由本次响应的 `agent_log` 归并而来：同一模块的“执行完成”事件与“状态完成”事件只计为一个步骤；原始 `agent_log` 保留在 `_build/raw_samples.json`。

| 业务步骤 | 执行模块 | 步骤说明 | 实际状态 |
|---|---|---|---|
| 学情诊断 | 学情诊断 Agent | 根据画像与前置测试判断难度、风格和盲区 | complete |
| 知识检索 | retrieval | 从领域知识库检索生成所需的证据 | done |
| 内容生成 | 知识生成 Agent | 生成讲义、实操指南和测试题 | complete |
| 内容审核 | 审核 Agent | 核查生成内容中的事实断言 | complete |
| 辩论裁决 | debate | 对存在分歧的断言进行裁决 | done |
| 保真修正 | 保真修正 Agent | 删除、替换或补充不可靠内容 | complete |
| 审核复核 | 审核 Agent | 对修正后的内容进行再次审核 | complete |
